사람들은 이렇게 써요

  • 5단계: 디자인 탭 → 프로토타입 모드 → 내용·컨셉·장수 입력 → High fidelity → 페이지별 수정
  • 2026 업데이트: Claude 메인 화면의 Design 탭으로 통합, 아티팩트 자동 저장, 디자인 시스템 재구축, 스크롤 연동 영상 애니메이션
  • 모바일 화면 7장을 1시간에: 맥락·목적 먼저, 시각 레퍼런스, 한 번에 하나씩 묶음 단위
  • 5단계: 디자인 시스템(.fig) 업로드 → PRD → 생성 → 인터랙티브 프로토타입 → Claude Code 로 개발 전달
  • PPT 제작에 최적화 — 디자인 시스템 먼저 만드는 순서가 중요
  • Figma 파일·폰트·로고를 올리면 디자인 시스템 자동 분석, Claude Code 로 핸드오프, PPTX·PDF 내보내기. 토큰 반영률 60~70%
  • 추출한 디자인 시스템을 넣으면 그 기준 안에서 일관된 디자인
  • 브랜드 정보를 프롬프트에 넣어 애니메이션 슬라이드 → 동적 웹사이트 → 제품 데모 → 릴스·숏츠·자막 → 여러 크기 배너 → 로고 애니메이션 순으로 7단계 모션그래픽을 만든다. 한 애니메이션을 여러 비율로 자동 변환 가능

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Photoshop — 레이어 합성과 이미지 편집으로 그래픽 디자인을 하는 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
