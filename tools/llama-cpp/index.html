이런 분께 추천

llama.cpp는 GGUF 형식의 대규모 언어 모델(LLM)을 내 컴퓨터에서 직접 실행하고 싶은 사람에게 맞는 오픈소스 C++ 라이브러리입니다. 클라우드 서비스에 데이터를 보내지 않고 로컬 환경에서 모델을 돌리고 싶은 개발자나 연구자에게 적합합니다. 기본적으로 C++로 만들어진 도구이므로, 직접 빌드하거나 라이브러리를 프로그램에 연결해 사용할 수 있는 개발 역량이 있는 사용자에게 더 잘 맞습니다. 이 도구의 가격이나 무료 여부, 최신 소식에 대한 정보는 제공된 내용에 없어 확인되지 않았습니다.

사람들은 이렇게 써요

  • Ollama처럼 localhost에서 모델을 띄워 기존 툴과 연결할 수 있는 도구로 소개된다
  • EmbeddingGemma 2를 지원하는 도구 중 하나다
  • llama serve -hf <모델이름>:IQ1_M 한 줄로 웹 화면이 있는 로컬 서버가 열린다. Ollama·Docker Model Runner·LM Studio·vLLM 에서도 같은 모델 이름으로 불러올 수 있다 (글 기준)
  • 「Gemma 4 31B 무검열 모델 GGUF 양자화 버전 소개」: Google Gemma 4 31B의 거절 응답을 줄인 무검열 변형 모델이 Hugging Face에 공개됐고, 여러 양자화 파일로 내려받을 수 있다.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • LM Studio — 로컬 컴퓨터에서 오픈 소스 언어 모델을 다운로드하고 실행하는 앱.
  • Stable Diffusion — 오픈소스 이미지 생성 모델로 로컬 GPU에서 실행한다.
  • Unsloth — 양자화된 모델을 GGUF 형식으로 변환하는 오픈소스 도구로 무손실 변환을 지원합니다.
  • VoiceStudio — 개인 컴퓨터에서 작동하는 오픈소스 음성 복제, 영상 더빙, 음성 합성 도구
