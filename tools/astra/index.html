Astra — 요금·무료 여부·쓰는 법

업데이트 2026-10-22

복잡한 프로젝트를 자동으로 완성하는 AI 에이전트 기술.

무료 여부확인 필요
가격확인 필요
관련 글 수9

사람들은 이렇게 써요

  • After Effects 수준의 모션그래픽을 자동으로 만들고, 생성한 After Effects 콜렉트 파일을 내려받아 바로 쓸 수 있다고 소개됨 (49,000원으로 제작)
  • 에이전트 기술로, 전에 실패했던 복잡한 프로젝트(UE5 시네마틱 PBR 마스터 매터리얼 구축)를 자동으로 완성했다고 소개됨
  • 스토리 구조·장면 분리·모순 찾기·QC 기준을 맡는 감독 역할 AI
  • Dots가 사용하는 모델로, 복잡한 추론 작업에서 더 우수한 성능을 낸다고 소개됐다
  • 작성자는 Astra 로 10분 걸리던 CAD 설계 작업을 Akan.js 로 30초 만에 끝낸다고 적었다
  • 작성자는 '아스트라 써라'라고만 적었다. 정리 글은 Astra 를 실시간 음성 대화 AI 로 풀이하고 Pro 기능을 포함해 구독할 수 있다고 했다.
  • Astra 가 빈 캔버스에서 고양이 그림 한 장을 331,254번의 붓질로 그렸다는 사례. 밑색→형태→털→눈과 수염 순서로 그렸다고 함 (글 설명, 작성자 측 수치).

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Aside — 로그인된 계정 내에서 이메일, 문서, 웹 작업을 자동으로 처리하는 AI 브라우저 에이전트
  • Grok Bot — xAI의 에이전트 서비스로 실제 업무 도구에 로그인해 자동으로 작업을 완료하는 AI 팀원
  • Hermes — AI 에이전트로, 사용자의 명령을 받아 자동으로 작업 단계를 수행할 수 있는 대규모 언어 모델 기반 기술
  • 3Blue1Brown — 수학과 과학을 시각적으로 설명하는 유튜브 채널의 스타일. 깔끔한 애니메이션으로 복잡한 개념을 전달한다.
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
