이런 분께 추천

leblog는 네이버 블로그를 운영하는 사람에게 맞는 윈도우 프로그램입니다. 블로그에 쓸 글감을 찾는 것부터 AI를 활용한 글쓰기까지 도와주는 것이 특징입니다. 작성한 글은 네이버 글쓰기 창에 자동으로 입력하고 임시저장까지 할 수 있다고 소개되어 있습니다. 글을 자주 올리고 싶지만 주제 찾기와 글 작성에 시간이 많이 드는 블로거에게 어울릴 수 있습니다. 다만 가격이나 무료 여부, 최신 소식에 대한 정보는 제공된 내용에 없어 확인이 필요합니다.

사람들은 이렇게 써요

  • 키워드와 상품을 고르면 AI 가 글을 쓰고 네이버 글쓰기 창에 자동 입력하는 윈도우 전용 프로그램. 글감→상품 정보→AI 글→사람 검수→네이버 임시저장 5단계. 실측 AI 글 생성 약 2분, 입력 약 3분 (작성자 실측). 기본 설정은 검수 + 임시저장, 하루 상한 30건은 즉시·예약 발행에만 적용.
  • 설치 뒤 한 달짜리 사용 키를 설정 탭 라이선스 칸에 넣고 활성화한다. 글 AI 키 하나는 꼭 필요하다(기본 DeepSeek, OpenAI·Anthropic·xAI 선택). 쓴 만큼 그 회사에 비용이 나가고 잔액이 없으면 글 생성이 실패한다
  • 기본값은 자동화 수준 '검수' + 업로드 '임시저장'(네이버에 비공개로 들어가 발행 전에 직접 확인). 글감은 정부24·청약홈·IT 뉴스 같은 정보 글감과 마이리얼트립·쿠팡파트너스·브랜드커넥트 제휴 글감
  • 키워드 찾기 탭에서 월 검색수·경쟁·추세를 보고 '경쟁 여유' 순으로 정렬한다. 상품이 1개뿐인 비교형은 정보형으로, 경험 메모가 빈 경험형은 리뷰 분석형으로 자동으로 바뀐다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

  • Uplika — Claude에 연결된 네이버 블로그 발행 플랫폼입니다
  • 21st — React 컴포넌트·템플릿·테마 12,000개 이상을 한곳에 모은 라이브러리로, Claude Code로 자동 생성 가능.
  • Dots — 오픈AI의 24시간 자동화 에이전트로, 사용자의 목표와 권한에 따라 업무와 생활 작업을 클라우드에서 자동 처리합니다.
  • Figma MCP — Figma와 AI를 연동해 디자인과 코드의 불일치를 자동 검수하는 도구
  • Freepik — AI 생성 리소스 집계 플랫폼으로 파트너 프로그램 제공
