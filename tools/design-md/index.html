가격확인 필요
관련 글 수4

사람들은 이렇게 써요

  • 디자인 시스템을 마크다운 한 파일에 적어 두면 Claude 같은 코딩 에이전트가 브랜드에 맞는 UI를 만든다. 색상값, 수치, 컴포넌트 규칙을 구체적으로 적을수록 결과가 맞는다고 한다 (글 기준)
  • 색·타입·간격·컴포넌트 참고 정보 파일. Claude·Cursor·ChatGPT 가 같은 스타일로 만들게 함
  • BMW M·마스터카드·메타 DESIGN.md 로 브랜드 스타일 PPT
  • 단순 색상표가 아니라 컴포넌트 상태와 인터랙티브 반응형 동작까지 담고, 따뜻한 크림색 편집 스프레드 같은 구체적인 비주얼 설명이 있어 AI가 의도를 정확히 이해한다
  • 디자인 업무 매뉴얼을 담은 파일로 AI에게 주입하면 색상·폰트·버튼을 실시간으로 바꿀 수 있다
  • 브랜드의 색상 값 폰트 여백 레이아웃 라운드 값이 변수로 들어 있고 해야 할 것과 하지 말아야 할 것 규칙이 문장으로 적혀 있어 프롬프트마다 새로 설명할 필요가 없다
  • DESIGN.md 는 색상·글자체·여백·컴포넌트 규칙을 AI 가 읽을 수 있게 적어 둔 문서 파일이다. 다른 서비스의 DESIGN.md 를 참고 자료로 넣으면 AI 기본 스타일 대신 그 디자인 규칙을 따라 화면을 만든다
  • 「디자인 작업을 돕는 AI 도구 8개 모음」 글에도 나온다. 글 요약: UI 디자인부터 검수까지 디자이너가 쓸 수 있는 AI 사이트와 스킬 8개.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
  • 21st.dev — 실험적인 UI 컴포넌트와 그 구현 코드 소스를 제공하는 인터랙션 디자인 레퍼런스 사이트다.
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리
  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • Mermaid — 순서도·다이어그램을 텍스트 코드로 만드는 오픈소스 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
