unlazy는 Claude 같은 AI가 작업을 끝냈다고 말하기 전에, 조건별 확인 명령을 실제로 실행해서 증거를 남기도록 돕는 오픈소스 스킬입니다. AI가 말로만 완료라고 보고하는 것이 걱정되는 개발자나, 결과를 검증 가능한 형태로 확인하고 싶은 팀에 맞습니다. 주어진 정보에는 가격이나 무료 여부가 나와 있지 않으므로, 이용 조건은 공식 자료에서 직접 확인해 보시기 바랍니다. 자세한 사용법이나 실제 사용 후기는 이 설명에 포함되어 있지 않습니다.

사람들은 이렇게 써요

  • '완주표'라는 검증 원장을 먼저 적는다: ① 조건(잴 수 있는 결과 한 줄) ② 확인 명령과 기대 문구 ③ 실제 실행 결과 ④ 재검 순서
  • 확인 명령이 exit 0(오류 없이 끝남)이고 기대 문구가 출력에 있어야만 [x] 로 체크한다. 보고 직전 모두 다시 검사하고, 못 지킨 조건은 '포기'로 남긴다
  • 원본은 검사를 하나씩 돌려 큰 작업에선 오래 걸린다. 완주표를 겹치지 않는 묶음으로 나눠 여러 서브에이전트에 맡기는 요령이 있다
  • 작업 전에 검증 체크리스트(GATES.md)를 먼저 쓰고 실행한 뒤 실제로 통과한 항목만 보고하게 한다. 깃허브 4천 스타 (작성자 수치)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Computer Use — AI가 마우스와 키보드를 직접 조작해 계산, 파일 열기 등 컴퓨터 작업을 수행하는 플러그인.
  • ECC — 오픈소스 Agent Harness로 Claude Code의 작업 환경을 구축하는 운영체계다.
  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • Humanizer — AI가 생성한 텍스트를 33가지 패턴의 다양한 톤으로 변환하고 자연스럽게 다듬는 Claude 스킬이다.
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
