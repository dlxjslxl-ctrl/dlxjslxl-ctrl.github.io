사람들은 이렇게 써요

  • 21st 에서 복사한 컴포넌트 코드나 프롬프트를 붙여넣어 쓰는 AI 코딩 도구 중 하나로 소개
  • DESIGN.md 파일을 입력해 쓸 수 있는 코딩 에이전트로 나왔다
  • 같은 습관 추적 앱 브리프로 비교했을 때 모바일 레이아웃과 AI 코치 응답에 문제가 있었다(코치가 응답하지 않는 장면이 나온다)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Beautiful UI — AI 네이티브 인터페이스를 위한 모던 UI 컴포넌트 라이브러리
  • Claude Design — Claude에서 UI/UX 디자인을 지원하는 아트보드 캔버스 기능
  • DESIGN.md — AI 에이전트를 위해 UI 디자인 규칙·색상·폰트를 구조화된 텍스트 포맷으로 정의하는 구글의 오픈소스 사양
  • Mobbin — 60만 개 이상의 실제 앱과 웹 화면 스크린샷을 모아 놓은 UI/UX 레퍼런스 라이브러리다.
  • Stitch — 텍스트 설명으로 UI 화면을 자동 설계하고 피그마로 내보내는 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
