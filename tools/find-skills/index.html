이런 분께 추천

find-skills는 필요한 작업에 맞는 스킬을 찾아 주는 스킬입니다. 어떤 작업을 해야 할지는 정해졌지만 어떤 도구나 스킬을 써야 할지 모르는 사람에게 맞습니다. 여러 스킬 중에서 원하는 일에 적합한 것을 고르고 싶을 때 참고할 수 있습니다. 제공된 정보에는 가격, 무료 제공 여부, 최신 소식이 없어서 이 부분은 확인할 수 없습니다. 자세한 사용 방법이나 세부 기능은 공식 자료를 살펴보시기 바랍니다.

사람들은 이렇게 써요

  • Vercel Labs 의 에이전트 스킬. 필요한 일을 말하면 맞는 스킬을 찾아 설치 방법을 안내함. 검색은 'npx skills find 키워드', 검색과 설치는 별개 단계. 찾은 스킬의 품질·안전성은 자동 보증되지 않음 (글 설명).
  • 스킬 장터를 검색해 설치 수가 적거나 별 100개 미만인 스킬을 거르고 설치 명령을 골라 준다고 소개됨 (글 기준 분야 1위 도구 목록에 포함).
  • 만들고 싶은 것을 말하면 여러 스킬을 뒤져 맞는 것을 찾아 설치해 주는 스킬. 스킬을 직접 찾는 시간을 줄여 준다
  • 하려는 일을 말하면(예: 콘텐츠 만들 스킬 찾아 줘) skills.sh 에서 맞는 스킬을 골라 설치 명령까지 안내한다. 10/28 기준 설치 수 410만 회로 skills.sh 전체 1위 (글 기준)
  • 「클로드코드에 맡기는 스킬 찾기 find-skills 설치와 확인법」 글에도 나온다. 글 요약: find-skills 로 하려는 일을 말하면 클로드코드용 스킬을 찾아 설치 전 정보와 함께 보여 준다 (글 기준)
  • 「요즘 뜨는 AI 도구·스킬 6개와 고민별 추천」 글에도 나온다. 글 요약: GitHub 새 저장소와 skills.sh 인기 스킬 중 고민별로 골라 쓸 수 있는 AI 도구 6개를 소개한다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • ui-ux-pro-max — 팔레트, 스타일, 폰트 조합 중 업종에 맞는 디자인 세트를 골라 주는 스킬
  • taste-skill — 디자인의 미적 판단 기준을 AI에게 주는 스킬
  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구
  • Agent Skills — 구글의 제품과 기술을 AI 에이전트가 정확하게 배우고 활용하도록 하는 기술 스킬 모음
  • AirLLM — 모델을 레이어 단위로 나눠 적은 GPU 메모리로 큰 언어 모델을 돌리게 해 주는 파이썬 라이브러리다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
