Astryx는 메타가 공개한 오픈소스 디자인 시스템으로, 150개 이상의 컴포넌트를 제공하고 테마를 커스터마이징할 수 있습니다. 화면의 UI 부품을 처음부터 새로 만들기보다 가져다 쓰고 싶은 개발자나 디자이너에게 잘 맞습니다. 여러 화면에서 디자인의 일관성을 유지해야 하는 팀이라면 풍부한 컴포넌트 목록이 작업의 기준으로 도움이 될 수 있습니다. 가격, 무료 여부, 최신 소식은 주어진 정보에 없으므로 공식 자료에서 직접 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 버튼·카드 등 150개 넘는 컴포넌트를 기본 제공하고 브랜드 테마를 만들 수 있다. 공개 코드와 CLI 는 상업 이용·수정 가능 (글 기준)
  • Meta 가 사내에서 8년간 키운 UI 디자인 시스템을 MIT 로 공개. 접근성 좋은 부품 150개 이상, CLI 로 부품 목록(npm run astryx -- component --list)을 볼 수 있다 (글 기준)
  • 13,000개 이상 앱에 쓰인 React 디자인 시스템. React 19 이상이 필요하고 CSS 변수만 바꾸는 테마 방식이라 컴포넌트 코드를 건드리지 않고 브랜드 색을 입힐 수 있다 (글 기준)
  • 「리액트 UI 컴포넌트 라이브러리 모음 10선」: 복붙해서 바로 쓸 수 있는 리액트 UI 컴포넌트·애니메이션 라이브러리 10곳을 정리했다
  • 「깃허브 트렌딩 TOP8 오픈소스 정리」: 깃허브 트렌딩에 오른 무료 오픈소스 8개(셜록, 오픈마우스봇, 무조코 등)를 한눈에 정리한 영상 요약
  • 「깃허브 트렌딩 오픈소스 TOP 11 정리 (11.10)」: 11월 10일 깃허브 트렌딩 오픈소스 11개를 정리했고 앤트로픽 스킬 공개와 메타 디자인 시스템이 핵심이에요

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • 21st.dev — 실험적인 UI 컴포넌트와 그 구현 코드 소스를 제공하는 인터랙션 디자인 레퍼런스 사이트다.
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리
  • DESIGN.md — AI 에이전트를 위해 UI 디자인 규칙·색상·폰트를 구조화된 텍스트 포맷으로 정의하는 구글의 오픈소스 사양
  • Design Bookmark — 2,500개 이상의 디자인·개발·AI 도구를 모아둔 큐레이션 디렉터리 사이트
  • Penpot — 오픈소스 디자인 및 프로토타이핑 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
