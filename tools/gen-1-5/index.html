GEN-1.5는 Generalist AI가 만든 로봇 기초 모델입니다. 주어진 설명에 따르면 적은 수의 시연만으로 새로운 작업을 배우고 수행할 수 있다고 합니다. 따라서 로봇에 새로운 동작을 빠르게 가르치고 싶은 로봇 연구자나 개발자에게 관심이 있을 만한 도구입니다. 다만 가격이나 무료 제공 여부에 대한 정보는 확인되지 않았으므로, 도입 전에 공식 자료를 살펴보는 것이 좋습니다.

사람들은 이렇게 써요

  • 시연 한 번(3~12초)을 보면 그 자리에서 새 작업을 한다. 지금까지 로봇은 수십 번의 시연과 별도 훈련이 필요했다고 한다 (글 기준)
  • 사람 손동작 영상만 보여 줘도 로봇이 자기 팔로 재현할 수 있고, 로봇 시연 영상이 아니어도 배운다고 한다 (글 기준)
  • 훈련에 없던 작업도 스스로 판단해 한다. 예로 종이로 덮인 그릇의 종이를 치우거나, 바나나를 빗처럼 써서 물건을 미는 모습이 소개됐다 (글 기준)
  • 원샷 학습 성공률은 약 59%이고 5분 데이터를 더하면 83% 수준이다. 단순 작업 기준이라는 제한이 있다 (작성자 수치)
  • 1~10번의 그래디언트 스텝(가중치 미세 조정)과 1~5분 데이터로도 새 작업을 배우고, 8개월간 훈련하며 성능이 계속 올랐다고 한다 (작성자 수치)
  • 연구자들이 이를 '로봇공학의 GPT-3 순간'이라 부른다고 한다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • ChatGPT Codex — 개발 환경에 ChatGPT 기능을 직접 통합하여 코딩 중에 이미지 생성 등의 작업을 바로 수행할 수 있게 하는 개발자 도구.
  • Computer Use — AI가 마우스와 키보드를 직접 조작해 계산, 파일 열기 등 컴퓨터 작업을 수행하는 플러그인.
  • FreeLLMAPI — 여러 AI 서비스의 무료 API를 연결해 사용 가능한 모델로 작업을 이어가게 돕는 도구
  • Gemini 3 — Google의 멀티모달 AI 모델로 이미지와 텍스트 기반 복잡한 작업을 처리할 수 있다.
  • Google Pics — 구글이 개발한 AI 기반 이미지 제작·편집 도구로 워크스페이스에 통합되어 있습니다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
