Figma Motion은 Figma에서 애니메이션과 모션 디자인을 다룰 수 있게 해 주는 기능입니다. 프로토타입 단계에서 화면 간 인터랙션과 움직임을 만들고 싶은 디자이너에게 맞습니다. 주어진 정보에는 가격이나 무료 제공 여부가 없으니 사용 전에 공식 안내를 확인하는 것이 좋습니다. 정적인 디자인을 넘어 움직임까지 함께 검토하고 싶은 팀에게 참고가 될 수 있습니다.

사람들은 이렇게 써요

  • 키프레임·타임라인·이징으로 UI 애니메이션을 만들고 Dev Mode 로 개발자에게 전달
  • 디자인 요소에 직접 애니메이션을 만들어 프로토타입이 쉬워짐
  • 애니메이션 스타일 오디오 타임라인 Lottie 내보내기 텍스트 애니메이션 네 가지 새 기능이 추가돼 애프터이펙츠에 한 걸음 더 가까워졌다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Midjourney — AI 이미지 생성 도구로, 텍스트 프롬프트를 입력해 고품질 이미지를 만들 수 있습니다.
  • Adobe Illustrator — 벡터 기반 그래픽 디자인 소프트웨어로 스티커 카드를 정밀하게 제작할 수 있다.
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리
  • Antigravity — AI를 활용해 디자인 요소와 이미지를 자동으로 생성하고 최적화하는 도구.
  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
