경량 파일 기반 데이터베이스로, Cloudflare Computer에서 Workspace의 권위 있는 상태를 저장한다.

이런 분께 추천

SQLite는 별도의 서버를 띄우지 않고 파일 하나로 동작하는 경량 데이터베이스입니다. 제공된 정보에 따르면 Cloudflare Computer에서 Workspace의 권위 있는 상태를 저장하는 데 쓰입니다. 그래서 작은 규모의 데이터를 간단하게 보관하려는 개발자나, Cloudflare Computer 환경에서 Workspace 상태를 관리하려는 사용자에게 맞을 수 있습니다. 다만 가격과 무료 제공 여부, 최신 소식에 대한 정보는 주어진 자료에 없어서 여기서는 확인할 수 없습니다.

사람들은 이렇게 써요

  • 「Cloudflare Computer AI 에이전트용 실행 환경」 글에 함께 나온 도구
  • 프로젝트별로 로컬 SQLite 데이터베이스에 저장돼 클라우드 걱정 없이 내 컴퓨터에서 관리한다
  • context-mode 가 작업 기록을 SQLite 에 저장해, 컨텍스트가 압축(compact)된 뒤에도 필요한 정보만 다시 찾아온다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.
