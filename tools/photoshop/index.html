Photoshop은 레이어 기반의 합성과 다양한 이미지 편집 기능을 제공하는 그래픽 디자인 도구입니다. 전문적인 수준의 디지털 이미지 작업이 필요한 디자이너나 사진 편집자에게 적합합니다. 복잡한 합성 작업이나 세밀한 이미지 보정이 필요할 때 유용하게 사용할 수 있습니다.

사람들은 이렇게 써요

  • 무료 대안 Compositor: 레이어·마스크·블렌드 모드·리퀴파이·배경 제거 지원
  • Photoshop 2025 에서 Nano Banana 가 정식 기능이 됐고, 화질 업스케일(2배·4배), 다이나믹 타입(텍스트 크기 자동 조정), 하모나이즈(조명·그림자 자동 보정)가 추가됨
  • Generative Fill 로 선택 영역에 프롬프트를 넣어 두 사람을 의자에 앉히는 식으로 구도를 바꾼다. 한 번에 안 되면 같은 영역에 다시 적용한다
  • 베타 버전에 추가된 Nano Banana 로 인물의 얼굴·착장·분위기는 유지하면서 전체나 특정 영역의 스타일만 바꾼다 (정식 버전에 추가 예정이라고 소개)
  • Lightroom 과 함께 AI 이미지의 색감·명암·질감을 조정해 완성도를 높인다
  • 클리핑 마스크·블렌드 단축키로 이미지를 합성하는 도구(2026)
  • Photoshop 2026의 Select Subject는 패브릭·메시 같은 투명 물체에서 배경까지 함께 선택하는 문제가 있어, Limits를 Discontiguous로 바꾸고 Tolerance 50%와 Find Edges를 쓰는 방법을 소개한다
  • Adaptive Wide Angle 필터는 Filter 메뉴의 Distort에 있으며, 렌즈 정보를 자동으로 인식하고 휘어 보이는 직선을 따라 선을 그으면 실제 직선으로 보정한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Adobe Illustrator — 벡터 기반 그래픽 디자인 소프트웨어로 스티커 카드를 정밀하게 제작할 수 있다.
  • Claude Design — Claude에서 UI/UX 디자인을 지원하는 아트보드 캔버스 기능
  • Comfy Cloud — ComfyUI 워크플로를 브라우저에서 실행할 수 있는 클라우드 기반 AI 이미지·영상 처리 서비스.
  • Dreamina — AI 기반 영상 제작 플랫폼으로 이미지 생성과 비디오 생성 통합 제공
  • ElevenLabs — 고품질 음성 합성과 음성 복제 기능을 제공하는 AI 음성 생성 플랫폼
