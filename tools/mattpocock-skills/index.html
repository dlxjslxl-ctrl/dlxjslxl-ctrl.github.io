mattpocock-skills는 요구사항 정리, TDD, 디버깅, 구조 개선처럼 실제 개발 현장에서 자주 쓰는 작업을 돕는 스킬 모음입니다. 소프트웨어를 만들면서 요구사항을 명확히 하거나 테스트 주도 개발을 연습하고 싶은 개발자에게 맞습니다. 버그 원인을 찾거나 기존 코드의 구조를 개선하려는 엔지니어에게도 도움이 될 수 있습니다. 다만 제공된 정보에는 가격이나 무료 여부, 최신 소식이 없으므로 사용 조건은 직접 확인해 보는 것이 좋습니다.

사람들은 이렇게 써요

  • /grill-me·/tdd·/improve-codebase-architecture 등 실전 엔지니어링 스킬 모음
  • GitHub에서 27만 5천 개의 별을 받은 AI 개발 스킬 모음이며, 새로 나온 chief-of-staff 스킬은 베타라 앞으로 동작이 바뀔 수 있다.
  • prototype 스킬은 완성품이 아니라 판단 근거용 코드를 빠르게 만들어 질문에 답하게 하며, npx skills add mattpocock/skills 로 설치한다
  • /grill-me 는 만들기 전에 AI 가 계속 질문하게 하고, /tdd 는 테스트부터 쓰게 하며, /diagnosing-bugs 는 감으로 고치지 않고 원인을 추적하게 한다. 실제 개발자가 매일 쓰는 방식을 Claude Code·Codex 스킬로 만든 것이라고 소개된다.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Google NotebookLM — 구글의 AI 기반 연구·정리 도구로 문서, 영상, 링크를 분석해 요약, 슬라이드, 팟캐스트를 자동 생성합니다.
  • REA — AI 에이전트가 앱과 바이너리를 분석해서 기능 구현 방식을 파악하고 재구현하도록 돕는 역공학 도구
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
  • shadcn UI — 대시보드와 실제 앱 UI를 위한 컴포넌트 라이브러리 및 스킬
  • ui-ux-pro-max — 팔레트, 스타일, 폰트 조합 중 업종에 맞는 디자인 세트를 골라 주는 스킬

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
