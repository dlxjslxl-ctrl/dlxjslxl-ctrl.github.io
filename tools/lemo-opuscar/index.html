lemo-opuscar는 코드만으로 영화 스타일의 단편을 만들고 싶은 사람에게 맞는 Claude용 skill입니다. 영상 편집 프로그램을 따로 다루지 않고 코드로 장면을 구성하는 방식에 익숙하다면 이 도구의 작동 방식을 자연스럽게 이해할 수 있습니다. 반대로 카메라 촬영이나 직접 영상을 편집하는 작업을 원하는 사람에게는 맞지 않을 수 있습니다. 제공된 정보에는 가격과 무료 여부, 최신 소식이 없으므로 이용 조건은 별도로 확인해 보시는 것이 좋습니다.

사람들은 이렇게 써요

  • 43가지 영화 스타일 프롬프트와 샘플 영상이 짝으로 제공되고, 스타일을 고르고 스토리를 넣으면 에이전트가 감독·촬영·작곡·음향까지 맡는다. 한 편에 30~60분이 걸리고 토큰도 많이 쓴다
  • 픽셀, 3D, 스케치 같은 스타일 영상도 코드로 뽑을 수 있다고 소개된다.
  • 51가지 영화 스타일 프롬프트와 데모 단편이 든 Claude Code 스킬. claude plugin marketplace add lemomo-ai/lemo-opuscar 후 claude plugin install lemo-opuscar@lemolab 로 설치한다
  • 59가지 영화 스타일 중 하나를 고르면 순수 코드로 짧은 영상을 만드는 Claude Code 스킬. 설치는 claude plugin marketplace add lemomo-ai/lemo-opuscar
  • 필름 스타일 수가 README 에는 51가지, 목록에는 59가지로 적혀 있다. 설치는 claude plugin marketplace add lemomo-ai/lemo-opuscar 다음 claude plugin install lemo-opuscar@lemolab. 스타일과 이야기를 말하면 에이전트가 감독처럼 코드로 단편 영상을 만든다
  • GitHub 별 약 5000개(작성자 수치)로 소개됐다. 스타일 수는 59가지인데 원문에는 51종으로도 적혀 있다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.
