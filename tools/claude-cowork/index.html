Claude Cowork — 요금·무료 여부·쓰는 법

업데이트 2026-10-17

Claude for Small Business의 통합 플랫폼으로 한 곳에서 모든 워크플로를 관리할 수 있다.

무료 여부확인 필요
가격확인 필요
관련 글 수14

사람들은 이렇게 써요

  • 파일 확인부터 최종 결과물까지 업무 전체를 맡기는 실행형 기능 — Claude Code 는 코드 실행 중심
  • 데스크톱 앱이 로컬 폴더와 연결돼 결과 자동 저장, 열 때마다 최신 데이터를 불러오는 대시보드
  • 별도 브랜드 종료 — 에이전트 기능이 일반 Claude 챗봇에 통합, 요청에 따라 자동 모드 전환
  • Cowork는 AI 에이전트가 내 컴퓨터에서 자율적으로 작업을 수행하게 하는 기능이고, Scheduled Tasks(예약 작업)는 매일 반복되는 자동화를 실행한다
  • 컴퓨터의 특정 폴더를 연결해 그 안의 파일을 통째로 읽고 정리와 작성을 시키는 기능이다. 폴더 접근 권한을 허용해야 하므로 관리자 승인 여부를 먼저 확인한다
  • claude.com/plugins 에서 바로 플러그인을 설치할 수 있다
  • 커넥터·MCP·스킬을 써서 업무를 자동으로 처리하는 모드로, 입력창 아래의 '채팅'을 'Cowork'로 바꿔 쓴다. 권한 모드 '모든 승인 건너뛰기'는 묻지 않고 Claude 가 판단해 모든 작업을 처리한다는 뜻이라, 처음에는 다른 모드로 작업 내용을 지켜보는 편이 안전하다
  • PPT 만드는 AI 를 순서대로 꼽은 글에서 셋째로 나온다. 정리 글은 복잡한 데이터나 구조를 논리적으로 정리하는 단계에 쓴다고 풀이했다.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Connect AI — 로컬에서 실행되는 AI 에이전트로, PayPal 매출 분석 등 비즈니스 작업을 자동으로 관리할 수 있다.
  • Dreamina — AI 기반 영상 제작 플랫폼으로 이미지 생성과 비디오 생성 통합 제공
  • Genspark — AI가 코드를 작성해주는 웹개발 플랫폼으로, 대화만으로 웹사이트를 만들 수 있다.
  • Google Flow — Google의 AI 기반 영상 제작 플랫폼으로 생성과 편집을 통합 지원한다.
  • Hostinger — VPS 호스팅 서비스로 Claude Code 프로젝트를 배포할 때 쓸 수 있다

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
