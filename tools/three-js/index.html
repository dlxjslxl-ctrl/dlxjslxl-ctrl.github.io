사람들은 이렇게 써요

  • Step 5 Preview 가 만든 3D 자산을 웹 앱에 연결
  • TSL(Three.js 셰이딩 언어) 셰이더로 물·하늘·조명 표현, 코드로 캠핑카·야자수·돌고래 생성
  • 3dviz-pro-max 가 웹 3D 씬을 만들 때 사용
  • 웹 브라우저에서 3D 그래픽을 그리는 JavaScript 라이브러리. AI 가 코드를 만들어 주어 그래픽 프로그래밍 지식 없이도 3D 인터랙션을 구현한다
  • 오픈소스 Eanpa Engine 을 붙이면 실시간 렌더링 장면에 동적인 하늘·날씨 환경을 더할 수 있다
  • 코드 기반 모션그래픽에서 3D 는 물리·공간(층·부품·배치·규모)을 설명할 때만 쓴다. 부드러운 키 라이트와 뒤쪽 림 라이트로 조명하고 카메라 각도는 35~55도, 평면을 정면에서 찍지 않는다
  • Opus 단독 3D 작업실 제작에 쓴 웹 3D 라이브러리
  • React Three Fiber가 React에서 쓸 수 있게 감싼 3D 웹 라이브러리로 나온다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • Canvas — 생성한 AI 이미지를 3D 모델이나 애니메이션으로 변환하는 도구
  • Comfy Cloud — ComfyUI 워크플로를 브라우저에서 실행할 수 있는 클라우드 기반 AI 이미지·영상 처리 서비스.
  • GSAP — 웹 애니메이션을 만드는 JavaScript 라이브러리로 업계 표준이다
  • Google AI Studio — 구글의 AI 모델을 브라우저에서 직접 테스트하고 실험할 수 있는 웹 플랫폼입니다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
