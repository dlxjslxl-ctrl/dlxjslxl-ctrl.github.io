사람들은 이렇게 써요

  • 한 Threads 작성자는 '클로드를 쓸 이유가 없다, 가격만 비싸고 마케팅 빨'이라며 Codex·Gemini·월 2만 원대 해외 도구를 대안으로 든다. 근거는 본인의 사용 경험뿐이고 비교 자료는 없다 (작성자 주장)
  • 블룸(전 Claude Bloom)은 국내에서 가장 큰 AI 커뮤니티로 소개되고, 거의 매주 세션이 열린다고 한다 (글 기준)
  • PC 에서 Claude 작업을 세션으로 계속 돌린 채 폰에서 그 창을 열어 원격으로 조종할 수 있다. 폰에 한 줄만 입력해도 작업 방향이 실시간으로 바뀌고, 작업이 끝나거나 확인이 필요할 때만 알림이 온다 (글 기준)
  • UI 디자인에는 Awesome Design(디자인 시스템 전달), Image2Code(스크린샷으로 HTML/CSS 생성), Taste(밋밋한 디자인 개선), Agent Browser(실제 브라우저 화면 캡처로 버그 수정), Design Guidelines Latest(배포 전 최신 규칙 검사) 다섯 가지를 연결하라는 정리가 소개됐다
  • 지침(내가 누구이고 어떻게 답할지 미리 입력)·메모리·프로젝트·파일 생성·아티팩트·업무 도구 만들기·커넥터·리서치·스킬·예약 작업의 10가지 기능을 4단계로 나눠 업무에 쓰는 방법이 정리됐다. 쇼핑몰 운영 예시가 중심이다
  • Claude 나 ChatGPT 에 상품 링크를 가져오라고 요청하는 방식과 게시 흐름을 자동화 스크립트로 묶는 방식이 한 글에서 언급됐다
  • 인스타그램 에이전트 스킬을 설치하면 릴스 대본, 일주일 콘텐츠 계획, 바이럴 분석을 자동화할 수 있다고 소개됐다
  • Higgsfield MCP 를 연결하면 아이디어를 글로 입력하는 것만으로 캐릭터·배경 에셋 생성부터 애니메이션 완성까지 2D 애니메이션 제작을 이끈다. 약 10분이면 된다고 한다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • ChatGPT Codex — 개발 환경에 ChatGPT 기능을 직접 통합하여 코딩 중에 이미지 생성 등의 작업을 바로 수행할 수 있게 하는 개발자 도구.
  • Claude Code — Anthropic의 코딩 AI 어시스턴트로, 코드 작성과 실행을 지원
  • Claude Opus 5 — Anthropic이 만든 고성능 AI 모델로 복잡한 코딩과 논리적 문제 해결에 최적화되어 있다.
  • Copilot — GitHub와 Microsoft가 제공하는 AI 코딩 어시스턴트로 CLI에서 활용 가능하다.
  • GitHub Copilot — 깃허브와 OpenAI가 만든 AI 코딩 보조 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
