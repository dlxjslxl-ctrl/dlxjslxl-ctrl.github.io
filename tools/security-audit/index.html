사람들은 이렇게 써요

  • Cloudflare가 만든 오픈소스 보안 감사 스킬로 여러 Sub-agent가 협력해 코드 구조 파악, 취약점 탐색, 후보 검증, 보고서 작성까지 처리한다. 찾은 취약점은 confirmed, needs_validation, rejected 세 가지로 분류한다
  • Cloudflare 가 내부에서 쓰던 취약점 탐지 스킬을 공개했다. 6단계: 정찰(architecture.md·coverage-ledger.json) → 여러 에이전트가 구역을 나눠 탐색 → 처음 보는 새 에이전트가 각 후보를 반박해 보는 검증 → 결과 구조화와 재검증(confirmed·needs_validation·rejected 를 findings.json 에 기록하고 스키마로 검사) →
  • 정찰→취약점 탐색→후보 검증→구조화 출력→독립 검증→보고서의 6단계. 단계마다 서로 다른 격리 에이전트를 써서 발견한 에이전트가 자기 발견을 검증하지 않게 해 오탐을 줄인다. 판정은 확정(confirmed)·추가 확인 필요(needs_validation)·기각(rejected)이며 확정은 전체 소스 추적과 관찰된 결과가 있어야 한다. 도구 호출과 병렬 하위 에이전트를 지원하는 모델, Node

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • security-audit-skill — AI 에이전트를 보안 감시자로 만드는 Node.js 기반 스킬로, 다단계 검증을 통해 객관적인 취약점 감사를 수행합니다.
  • Aside — 로그인된 계정 내에서 이메일, 문서, 웹 작업을 자동으로 처리하는 AI 브라우저 에이전트
  • Astra — 복잡한 프로젝트를 자동으로 완성하는 AI 에이전트 기술.
  • Grok Bot — xAI의 에이전트 서비스로 실제 업무 도구에 로그인해 자동으로 작업을 완료하는 AI 팀원
  • OpenClaw — 오픈소스 AI 코딩 에이전트.
