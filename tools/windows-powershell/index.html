Windows PowerShell — 요금·무료 여부·쓰는 법

업데이트 2026-10-25

윈도우 시스템을 제어하는 명령줄 도구로, 앱 삭제 등 고급 설정에 사용된다.

무료 여부확인 필요
가격확인 필요
관련 글 수1

사람들은 이렇게 써요

  • 관리자 권한으로 실행해 Get-AppxPackage와 Remove-AppxPackage 명령어를 입력하면 윈도우 기본 날씨앱(Microsoft.BingWeather)을 삭제할 수 있다
  • 윈도우에서 REA 를 설치할 때 node -v, npx rea-agents@latest setup, npx rea-agents@latest doctor 명령을 PowerShell 에 입력한다.
  • Claude Code 에 Hermes Agent 설치를 맡기면 PowerShell 기준으로 설치가 진행되고, 설치가 끝나면 PowerShell 에서 hermes 명령으로 실행한다.
  • 한 줄 명령으로 윈도우 기본 앱 정리 스크립트를 불러와 실행하는 방법이 소개됨 (삭제 전 복원 지점 먼저)
  • ChatGPT Codex 설치 명령을 PowerShell(윈도우 명령 창)에 붙여 넣어 설치한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • CapCut — 모바일 및 데스크톱 비디오 편집 도구로 생성된 자막 파일을 임포트해 편집할 수 있다.
  • ChatGPT Work — 클라우드 브라우저와 고급 AI 기능을 제공하는 ChatGPT의 업무용 구독 상품
  • Deep Glow 2 — After Effects용 글로우 이펙트 플러그인으로 고급 조명 표현이 가능함
  • Figma — 온라인 협업 디자인 도구로 스티커 레이아웃을 구성하고 다양한 크기로 조정할 수 있다.
  • GPT Image 2 — OpenAI의 고급 이미지 생성 모델로 상세하고 일관성 있는 이미지를 만든다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
