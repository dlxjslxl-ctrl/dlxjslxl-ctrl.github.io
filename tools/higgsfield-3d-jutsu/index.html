텍스트 프롬프트로 3D 장면의 블록아웃을 자동 생성하는 AI 도구.

무료 여부확인 필요
가격확인 필요
관련 글 수3

사람들은 이렇게 써요

  • 도로·자동차·카메라 움직임을 3D 로 미리 구성해 화면으로 확인하는 프리비즈 도구. 블록아웃 → 프리비즈 → AI 렌더링 → 최종 영상 순서로 쓴다
  • 게임의 시각 요소를 만드는 데 쓰인 Higgsfield 기능 중 하나
  • Blender 기반으로 텍스트 프롬프트에서 3D 모델과 장면을 만든다. GPT 6 Astra 와 이어 기본 3D 뷰포트에서 전투 시스템·NPC·인터페이스가 있는 RPG 프로토타입까지 만들었다
  • GPT-6 Astra 를 골라 프롬프트로 3D 블록아웃을 만들고 GLB 파일로 내보낼 수 있다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Adobe Firefly — 텍스트 입력으로 이미지를 생성하고 편집할 수 있는 Adobe의 생성형 AI 도구입니다.
  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • Cursor — AI 기반 코드 편집기로 프롬프트로 코딩을 수행한다.
  • Figma MCP — Figma와 AI를 연동해 디자인과 코드의 불일치를 자동 검수하는 도구
  • GPT 6 Astra — OpenAI의 텍스트·이미지·영상·코드를 통합해서 이해하는 멀티모달 모델

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
