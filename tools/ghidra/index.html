Ghidra는 오픈소스 역어셈블리 및 디컴파일 도구입니다. 실행 파일의 동작을 분석하고 싶은 보안 연구자나 리버스 엔지니어링을 배우려는 학생에게 맞는 도구로 볼 수 있습니다. 소프트웨어의 기계어 코드를 읽기 쉬운 형태로 살펴보고 싶은 개발자에게도 참고할 만합니다. 다만 주어진 정보에는 가격이나 무료 여부, 최신 소식에 대한 내용이 없어 이 부분은 직접 확인해 보시는 것이 좋습니다.

사람들은 이렇게 써요

  • 무료 역어셈블리 도구로 REA와 연결해 바이너리 수준까지 분석한다
  • REA가 에이전트에 연결해 주는 역공학 도구 중 하나로, 에이전트가 디컴파일러를 직접 제어해 함수 호출 흐름을 파악한다.
  • Hopper와 함께 네이티브 바이너리 분석에 필요한 엔진이며, 정적 JavaScript 분석에는 두 엔진이 필요 없다.
  • REA 가 AI 에이전트와 이어 쓰는 기존 분석 도구 가운데 하나로 Hopper·IDA 와 함께 꼽힌다
  • 네이티브 앱 분석에 필요한 Hopper·Ghidra·IDA 가운데 무료 오픈소스인 Ghidra 로도 충분하다고 한다. 실험에서는 REA 없이도 에이전트가 직접 Ghidra 를 실행해 문제를 풀었다
  • 미국 NSA 가 만들고 관리하는 오픈소스 역공학 도구로 Apache 2.0 라이선스로 무료 공개돼 있다. 실행 파일의 기계어를 C 언어와 비슷한 코드로 바꿔 보여 주고 함수 호출 관계를 그래프로 그려 준다. Windows·macOS·Linux 에서 실행되며 실행 전에 JDK 25(64비트)를 설치해야 한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구
  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • DESIGN.md — AI 에이전트를 위해 UI 디자인 규칙·색상·폰트를 구조화된 텍스트 포맷으로 정의하는 구글의 오픈소스 사양
  • ECC — 오픈소스 Agent Harness로 Claude Code의 작업 환경을 구축하는 운영체계다.
  • Flux — 무료 오픈소스 이미지 생성 모델이다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
