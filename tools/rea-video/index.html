rea-video는 영상을 장면(镜头) 단위로 나누어 분석하고, 그 영상이 어떤 방식으로 만들어졌는지 알아내어 비슷하게 만들 방법을 제안하는 도구입니다. 영상이 어떻게 구성되었는지 궁금하거나, 좋아하는 영상의 제작 방식을 참고해 자신의 영상을 만들고 싶은 영상 제작자에게 맞을 수 있습니다. 다만 가격, 무료 제공 여부, 최신 소식에 대한 정보는 주어진 자료에 없으므로 사용 전에 직접 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • AI 영상이면 샷마다 프롬프트를 거꾸로 추정하고, 비슷한 샷을 묶어 생성 횟수를 줄인다. README 예시: 8개 샷 → 3번 생성 (작성자 수치)
  • 실사면 장면 수 · 카메라 위치 · 샷 크기 · 카메라 움직임 · 조명 · 색보정을 분석하고, 코드 모션이면 Remotion 프로젝트 하나로 만들 수 있다고 알려 준다 (예시: 70초 홍보영상의 83%가 코드 모션)
  • 자막 시간을 SRT · ASS 로 내보내고 배경음악 BPM 과 효과음 위치도 표시한다
  • 정확도(작성자 테스트): 원본 파일 98% 이상, 플랫폼에서 받은 압축 영상 88.6%, 이미지 판독 모델을 붙이면 99% 이상
  • 결과물은 핵심 프레임 사진이 붙은 복제 제작 보고서(report.html)이고, 실사 · AI · 코드 작업을 나눠 적는다
  • Gemini 나 豆包 같은 이미지 인식 모델의 API 주소와 키를 주면 판별이 더 정확해진다. 압축 영상은 노이즈 정보가 사라져 이 도움이 필요하다
  • 남의 영상을 복제해 그대로 다시 올리면 원작자 권리를 침해할 수 있으니 참고용으로만 쓴다
  • 릴스를 샷으로 쪼개 실사·AI·코드 제작 여부를 판별하고, AI 장면은 프롬프트를 거꾸로 추정한다. 자막 시간·색·등장 방식, 컷 위치·속도를 분석해 SRT·ASS 로 내보낸다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Lemo Opuscar — 코드로 스타일 영상을 만들어 주는 프로젝트
  • AirLLM — 모델을 레이어 단위로 나눠 적은 GPU 메모리로 큰 언어 모델을 돌리게 해 주는 파이썬 라이브러리다.
  • AI 영상 생성 모델 — 동작 참조 영상과 인물 이미지를 조합해 새로운 인물이 특정 동작을 수행하는 영상을 생성하는 AI 도구.
  • After Effects — Adobe의 모션그래픽 및 영상 효과 제작 소프트웨어
  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
