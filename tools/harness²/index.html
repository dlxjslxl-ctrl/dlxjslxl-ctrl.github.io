Harness²는 AI 에이전트가 쓰는 프롬프트, 스킬, 메모리 같은 실행 설정을 자동으로 시험하고 개선하는 오픈소스 프레임워크입니다. 에이전트의 동작 설정을 체계적으로 바꿔 가며 성능을 높이고 싶은 개발자나 연구자에게 맞는 도구입니다. 오픈소스라서 소스 코드를 직접 확인하고 자신의 환경에 맞게 수정해 사용할 수 있습니다. 다만 가격이나 무료 제공 여부에 대한 정보는 주어진 자료에 없으므로, 사용 전에 공식 저장소에서 따로 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 같은 작업을 여러 설정으로 돌려 비교하는 '작업 단위 재귀'를 정답 피드백 없이 Propose(수정안 제안)–Probe(같은 작업에 실험)–Compose(차이를 바탕으로 합치기) 세 단계로 한다
  • '하네스 단위 재귀'는 채택된 설정과 근거가 확실한 교훈을 쌓아 다음 작업 개선에 다시 쓴다
  • 논문은 GLM-5·Gemini 3.5 Flash 로 한 단계만에 WorkBuddy-Bench 최대 11.5점, JobBench 4.5점, LAB 부분 통과율 11.8%p 향상을 보고했다 (논문 수치)
  • 벤치마크 실행 때 --k 는 작업 단위 재귀 횟수, --mode 는 parallel 또는 sequential. 모델 호출에 API 비용이 들어 작은 작업으로 먼저 시험하는 것이 좋다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Impeccable — AI 생성 디자인의 반복적인 패턴을 제거하고 전문가 수준으로 개선하는 오픈소스 도구
  • Matt Pocock's Skills — AI 코딩 에이전트의 실제 개발 문제를 해결하는 재사용 가능한 스킬 모음
  • Prompts.chat — 2,000개 이상의 커뮤니티 프롬프트를 MCP로 AI 도구에 연결해 자동으로 적용하는 오픈소스 플랫폼
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리
