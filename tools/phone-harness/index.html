phone-harness는 AI 에이전트가 실제 스마트폰을 원격으로 조작하고 화면을 제어할 수 있게 해 주는 오픈소스 도구입니다. 스마트폰 자동화나 모바일 화면 테스트를 AI 에이전트에게 맡기고 싶은 개발자에게 맞습니다. 다만 가격이나 무료 여부에 대한 정보는 주어진 자료에 없으므로 직접 확인이 필요합니다. 최신 소식에 대한 내용도 없으니 공식 저장소나 문서를 참고하는 것이 좋습니다.

사람들은 이렇게 써요

  • GitHub 에서 별 1,998개를 받은 오픈소스라고 소개된다 (작성자 수치)
  • 연결은 맥 한 대로 한다. 아이폰은 맥의 아이폰 미러링 창을 거치고, 안드로이드는 adb 로 USB 나 와이파이로 붙는다
  • 탈옥, Xcode 설치, 폰에 따로 앱 설치가 필요 없다고 한다 (글 기준)
  • 활용처로 실제 기기가 필요한 모바일 테스트 자동화, 반복적인 앱 작업 자동화, 크로스 플랫폼 에이전트 개발이 꼽힌다. 작성자는 '저장해 두면 쓸 데가 있어서 가져왔다'고만 말해 직접 써 본 후기는 없다
  • 「Claude Code로 내 아이폰을 조작하는 오픈소스 phone-harness」: Claude Code가 아이폰 화면을 글자로 읽고 탭·스와이프해 폰 심부름을 대신해주는 오픈소스 phone-harness를 실사용 테스트했다
  • iph 와 같은 목적(아이폰 직접 조작)의 도구로 영상에서 함께 비교됐다 (글 기준)
  • Phone Harness 는 맥의 '아이폰 미러링' 화면을 찍어 분석하고 터치 좌표를 눌러 Claude Code 같은 에이전트가 아이폰을 조작하게 하는 오픈소스 도구 (글 기준, 대본 없이 제목·설명만 정리됨)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • chrome-devtools-mcp — AI 에이전트가 실제 Chrome 브라우저의 개발자 도구 기능을 사용할 수 있게 해 주는 MCP 서버다.
  • earshot — 코딩 에이전트가 소리를 듣고, 검토하고, 코드로 소리를 만들 수 있게 해 주는 CPU 전용 오픈소스 도구.
  • Blender MCP — ChatGPT가 Blender를 원격으로 제어할 수 있도록 연결해주는 애드온
  • OpenUI — AI 모델이 만든 화면을 스트리밍으로 바로 그려 주는 오픈소스 Generative UI 프레임워크.
  • Refero MCP — UI 설계 전 실제 앱 화면을 조사하고 비교할 수 있는 MCP

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
