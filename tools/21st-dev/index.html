21st.dev는 실험적인 UI 컴포넌트와 그 구현 코드 소스를 제공하는 인터랙션 디자인 레퍼런스 사이트입니다. 새로운 화면 요소를 찾아보거나 인터랙션 아이디어를 얻고 싶은 디자이너와 프론트엔드 개발자에게 맞습니다. 참고 자료로 컴포넌트를 살펴보고 코드를 확인하는 용도로 활용할 수 있습니다. 가격이나 무료 여부에 대한 정보는 제공된 내용에 없어 확인이 필요합니다.

사람들은 이렇게 써요

  • 12,000개 이상의 React 컴포넌트·템플릿·테마 모음. Copy Component 나 Prompt 버튼으로 복사해 Claude Code·Cursor·v0 에 붙여넣는다. shadcn/ui·Tailwind CSS 와 호환되고 외부 라이브러리에 기대지 않는 Copy-and-Own 방식이라 색·글꼴·레이아웃을 전부 고칠 수 있다. 마케팅 블록 2,000개 이상, UI 컴포넌트 2,100개 이
  • React 컴포넌트, 템플릿, 테마 12,000개 이상을 제공하며 AI용으로 최적화된 코드 예시를 제공한다
  • React 컴포넌트 12,000개 이상, 컴포넌트마다 프롬프트가 붙어 Claude Code·Codex·Lovable 에 그대로 붙여 넣어 쓴다 (작성자 수치)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • DESIGN.md — AI 에이전트를 위해 UI 디자인 규칙·색상·폰트를 구조화된 텍스트 포맷으로 정의하는 구글의 오픈소스 사양
  • Lazyweb — 앱과 웹의 우수한 화면 디자인 25만 장을 모아 AI 코딩에 참고자료로 제공하는 디자인 라이브러리.
  • Mobbin — 60만 개 이상의 실제 앱과 웹 화면 스크린샷을 모아 놓은 UI/UX 레퍼런스 라이브러리다.
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
  • Adobe Illustrator — 벡터 기반 그래픽 디자인 소프트웨어로 스티커 카드를 정밀하게 제작할 수 있다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
