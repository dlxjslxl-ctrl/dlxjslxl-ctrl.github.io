사람들은 이렇게 써요

  • Claude Opus 5.5 와 함께 모션그래픽·설명 영상·3D 장면·게임 389개를 만든 스킬. 터미널에서 /hyperframes 로 실행한다
  • Claude 터미널에 설치해 Opus 5.5가 Canvas·SVG·GSAP·Three.js로 모션을 코드로 만드는 스킬
  • /brag가 음악·효과음·자막 영상을 렌더링할 때 쓰는 번들
  • Claude Code 안에서 쓰는 무료 AI 영상 편집 스킬
  • HTML을 쓰면 비디오로 렌더링해 주는 도구로 에이전트 자동화에 맞게 만들어졌다
  • Remotion과 함께 AI가 영상 프레임과 모션을 자동으로 만들어 모션그래픽 제작 시간을 줄인다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Getdesign.md — 마크다운 파일을 프레젠테이션 슬라이드로 변환하는 오픈소스 도구로 자동 디자인을 적용한다.
  • Google NotebookLM — 구글의 AI 기반 연구·정리 도구로 문서, 영상, 링크를 분석해 요약, 슬라이드, 팟캐스트를 자동 생성합니다.
  • Paperclip — 자연어로 AI 에이전트 회사 구조를 자동 생성·관리하는 오픈소스 프레임워크.
  • PixVerse — 이미지와 텍스트를 동영상으로 변환하는 AI 영상 생성 플랫폼이며 V4.5 모델을 지원한다.
  • Skillry — Claude Opus 5.5로 만든 AI 영상 프롬프트와 결과물을 모아 둔 갤러리 및 영감 라이브러리

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
