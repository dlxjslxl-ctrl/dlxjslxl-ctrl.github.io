이런 분께 추천

Adobe Illustrator는 벡터 기반의 그래픽 디자인 소프트웨어로, 스티커나 카드 같은 디자인을 정밀하게 만들고 싶은 사람에게 맞습니다. 로고, 일러스트, 타이포그래피 등 다양한 디자인 작업이 필요한 전문가나 학생들이 사용하기 좋습니다.

사람들은 이렇게 써요

  • Smooth 도구로 경로 모서리를 부드럽게 만드는 벡터 편집 도구
  • Illustrator 2027의 3D and Materials 패널에는 Object·Materials·Lighting 탭이 있어 텍스트에 입체 효과와 재질, 조명을 줄 수 있다
  • 펜슬 툴은 Fidelity를 Accurate 쪽으로 두면 세밀한 선이, Smooth 쪽으로 두면 부드러운 곡선이 나온다. Fill new pencil strokes를 켜면 그린 선이 자동으로 채워지고, Close paths 옵션은 끝점이 가까우면 도형을 자동으로 닫는다
  • Shape Builder는 겹친 도형을 클릭해 합치거나 빼고, Clipping Mask는 위쪽 도형 모양으로 아래 이미지를 자른다. Envelope Distort는 도형을 휘거나 늘리고, Draw Inside는 선택한 도형 안쪽에만 그려지게 한다
  • 속성 패널의 Concept to Vector(개념을 벡터로) 옵션에서 선 아트·드로잉·기하학적 같은 스타일을 골라 PNG를 벡터로 바꾼다. Match Reference Image 슬라이더로 원본과 얼마나 가깝게 따라갈지 조절하고 Raster Output 체크는 꺼 둔다
  • 턴테이블 기능은 창(Window)의 속성(Properties) 패널에 있으며 캐릭터 디자인·제품 시안·패키지 디자인에서 애매한 각도의 이미지를 빠르게 조정하는 데 유용하다
  • 선택 도구(Selection Tool)와 Alt+Click을 함께 쓰면 겹친 도형들 중에서 필요한 부분만 선택할 수 있다
  • 2026 베타의 Sketch to Vector 기능이 손으로 그린 스케치나 스캔 이미지를 클릭 한 번으로 정리된 벡터 라인 아트로 바꿔 준다. 아직 공식 출시 전 베타 기능이다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Figma — 온라인 협업 디자인 도구로 스티커 레이아웃을 구성하고 다양한 크기로 조정할 수 있다.
  • Gemini 3 — Google의 멀티모달 AI 모델로 이미지와 텍스트 기반 복잡한 작업을 처리할 수 있다.
  • Google Colab — 클라우드 기반 주피터 노트북으로 강화학습 코드를 무료로 실행하고 로봇 두뇌를 훈련할 수 있다.
  • TouchDesigner — 노드 기반 프로그래밍으로 실시간 비주얼과 인터랙티브 경험을 만드는 VFX·그래픽 제작 플랫폼.
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
