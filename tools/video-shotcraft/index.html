이런 분께 추천

video-shotcraft는 Claude Code와 Codex에서 사용할 수 있는 Remotion 기반 영상 제작 skill입니다. 코드로 영상을 만들어 보고 싶은 개발자나, AI 코딩 도구 안에서 영상 작업을 함께 처리하고 싶은 사람에게 맞는 도구로 볼 수 있습니다. 주어진 정보에는 가격이나 무료 여부, 최신 소식이 없으므로 이 부분은 직접 확인해야 합니다. 구체적인 기능 목록은 정보에 없어서 사용 전에 공식 자료를 살펴보는 것이 좋습니다.

사람들은 이렇게 써요

  • 숏 레시피 카드 152개를 참고해 영화 같은 제품 영상을 만든다 (약 12800 star, 작성자 수치)
  • 150개 샷 레시피 중 골라 홍보 영상을 완성한다. 1.3만 스타 (작성자 수치)
  • AI 가 영상을 직접 생성하지 않고, 내 스크린샷과 문구를 코드로 그려 편집 가능한 영상을 만든다. 실제 페이지를 캡처하고 분镜 레시피에서 샷을 골라 Remotion 으로 움직인다
  • 124개 분镜 카드(150개 샷)와 미리보기가 있고, 카드 이름을 지정해 연출을 고를 수 있다
  • 결과물: 1920×1080 · 30fps · h264 MP4, 음악과 효과음 포함. Ink Press 템플릿(36초 샘플)이 시작점
  • 완성 후 브라우저의 Motion Workbench 에서 자막 · 샷 · 효과음 트랙을 고쳐 다시 렌더링한다. 2026-08 업데이트로 剪映(JianYing) 초안 내보내기 추가

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Dreamina — AI 기반 영상 제작 플랫폼으로 이미지 생성과 비디오 생성 통합 제공
  • Google Flow — Google의 AI 기반 영상 제작 플랫폼으로 생성과 편집을 통합 지원한다.
  • Newtake — 노드 기반 AI 영상 제작 플랫폼으로 이미지·영상·효과를 한 캔버스에서 통합 편집 가능.
  • Taste Skill — Claude Code 기반 프론트엔드 프레임워크로 빠른 프로토타입 제작을 지원
  • After Effects — Adobe의 모션그래픽 및 영상 효과 제작 소프트웨어
