항공우주 정비 문서용 통제 언어로, 명확하고 간결한 표현을 강제하는 언어 스펙.

무료 여부확인 필요
가격확인 필요
관련 글 수3

사람들은 이렇게 써요

  • 항공 정비 문서용 통제 언어 규격. "80%만" 요청해 AI 출력을 명확하게 만든다
  • 엄격한 명세로 AI 출력을 명확하게 만드는 항공우주 정비 통제 언어
  • 한 번에 올바로 이해되게 설계된 항공기 정비 매뉴얼용 통제 영어 표준
  • 군더더기 없는 문장을 만드는 통제 언어(80%만 요청 가능)
  • 항공기 정비 매뉴얼을 위해 만든 영어 규격으로 한 문장 최대 20단어, 설명은 25단어 이내, 승인어 약 900개만 쓰도록 엄격히 제한한다. LLM이 이 규격을 잘 알아서 이름만 언급해도 간결한 문체로 답한다고 한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Claude Fable — Anthropic의 초장문 컨텍스트와 강화된 추론을 지원하는 언어 모델
  • Claude Opus 5.5 — Anthropic에서 만든 최신 대규모 언어 모델로 Opus보다 저렴하고 빠르다.
  • Python — 프로그래밍 언어
  • TypeSafe AI — Jev 쿼리 언어로 AI의 의사결정을 검증하고 구조화된 출력을 얻는 플랫폼.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
