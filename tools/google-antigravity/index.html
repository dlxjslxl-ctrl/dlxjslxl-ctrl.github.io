이런 분께 추천

Google AntiGravity는 에이전트형 IDE로, 브라우저와 개발 환경을 연결해 코드를 자동으로 실행하고 수정하는 개발 도구입니다. 그래서 반복적인 코드 실행과 수정 작업을 줄이고 싶은 개발자에게 잘 맞을 수 있습니다. 제공된 정보에는 가격이나 무료 여부, 최신 소식이 없으므로 이 부분은 공식 사이트에서 직접 확인하는 것이 좋습니다. 자동화 기능을 실제 프로젝트에 적용하기 전에는 기능 범위와 사용 조건을 먼저 살펴보는 것이 안전합니다.

사람들은 이렇게 써요

  • 브라우저와 개발 환경을 연결해 코드를 스스로 실행·수정·리팩토링하고 테스트·디버깅까지 진행하는 에이전트형 IDE
  • 구글의 에이전트 IDE로 스티치 MCP 서버를 설치하고 디자인을 Import하면 React 코드가 자동 생성된다
  • Scientific Agent Skills(과학 연구용 스킬 177개)를 붙여 쓸 수 있는 에이전트로 소개됨

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Anthropic Claude API — Anthropic의 클로드 AI 모델을 API 형태로 제공하며, ComfyUI에 연결해 자동으로 프롬프트를 생성할 수 있다.
  • Harness² — AI 에이전트의 프롬프트·스킬·메모리 등 실행 설정을 자동으로 시험하고 개선하는 오픈소스 프레임워크다.
  • Prompts.chat — 2,000개 이상의 커뮤니티 프롬프트를 MCP로 AI 도구에 연결해 자동으로 적용하는 오픈소스 플랫폼
  • Superpowers — 시니어 웹엔지니어의 개발 방법론(계획→테스트→실행→검토)을 Claude가 학습하도록 만든 개발 스킬이다.
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
