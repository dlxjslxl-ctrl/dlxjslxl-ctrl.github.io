Dots는 사용자의 목표와 권한에 따라 업무와 생활 속 작업을 클라우드에서 자동으로 처리해 주는 AI 도구입니다. 설명에 따르면 24시간 동작하는 자동화 에이전트이므로, 반복적인 일을 맡기고 싶은 사람에게 잘 맞습니다. 다만 가격이나 무료 이용 조건에 대한 정보는 제공된 자료에 없으니 사용 전에 공식 안내를 확인하는 것이 좋습니다. 자동으로 작업이 처리되는 만큼, 어떤 권한을 주는지 미리 살펴보는 것도 필요합니다.

사람들은 이렇게 써요

  • 클라우드에서 24시간 자동 작업을 지속하는 오픈AI 에이전트
  • 24시간 모니터링, 자동 재시작, 긴급 중단 기능으로 봇을 안정적으로 운영하는 플랫폼이다
  • OpenAI가 공개한 항상 켜져 있는 AI 어시스턴트로, 공개되자마자 오픈소스 대체제 OpenDots가 나왔다
  • PC 연결이 가능해 Windows나 Mac에서 직접 작업을 실행할 수 있고 Astra 모델로 복잡한 추론에서 더 우수한 성능을 보인다. 복잡한 추론이나 PC 직접 제어에는 Dots를 고른다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Browser Use — 웹사이트를 직접 조작하는 AI 에이전트로, Jev와 연결해 자동화 작업을 할 수 있다
  • Connect AI — 로컬에서 실행되는 AI 에이전트로, PayPal 매출 분석 등 비즈니스 작업을 자동으로 관리할 수 있다.
  • Muse — 메타가 공개한 AI 에이전트로 이메일·쇼핑·예약 등 실제 작업을 자동으로 수행하는 개인용 AI 어시스턴트
  • 21st — React 컴포넌트·템플릿·테마 12,000개 이상을 한곳에 모은 라이브러리로, Claude Code로 자동 생성 가능.
  • Aside — 로그인된 계정 내에서 이메일, 문서, 웹 작업을 자동으로 처리하는 AI 브라우저 에이전트
