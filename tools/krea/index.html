사람들은 이렇게 써요

  • 새 이미지 생성 모델 Krea 3 가 8월 27일 뉴욕에서 첫 공개 쇼케이스를 열 예정이라는 예고 글이 있다. 프리뷰 신청은 댓글이나 공식 채널로 한다. 이후 출시 소식은 Krea 3와 Krea Agents 출시, 강화된 편집 기능 제공 에 있다 (글 기준)
  • 이전 Krea 2 처럼 오픈될 것으로 예상되고, 사용자들이 이미지 편집 모델 탑재를 강하게 요청하고 있다고 한다 (글 기준)
  • Krea 안의 Seedream Pro 로 영상 모션을 만들어 보통 10초를 생성한 뒤 가장 좋은 3~4초를 고른다
  • Enhance 기능으로 흐릿한 사진을 고화질로 바꾼다. 1분 안에 결과가 나오고 AI Strength·Resemblance·Clarity·Sharpness 로 조절한다. 이미지 생성·편집·3D 객체 생성도 되는 AI 크리에이티브 스위트
  • 무료 AI 이미지 생성 도구로 하루 3분간 무료 렌더링 시간이 있고 한국어 프롬프트를 영어로 번역해 쓴다
  • 새 기본 모델 Krea 3(편집 기능 강화)와 에이전트 워크플로용 플랫폼 Krea Agents 가 나왔다. MCP 나 API 로 기존 워크플로·다른 에이전트와 연결할 수 있다
  • 「입자 효과로 피는 꽃 인터랙티브 웹 경험 만들기」 글에도 나온다. 글 요약: Midjourney 이미지, Krea 애니메이션, Kimi K3로 입자 기반 꽃 피는 장면의 인터랙티브 웹사이트를 제작한 사례. (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Qwen-Image-2.1 — 텍스트 입력과 이미지 편집을 통합 처리하는 경량 오픈소스 이미지 생성·편집 모델로, 투명 배경과 다중 참고 이미지를 지원합니다.
  • Runway — AI 영상·이미지 편집 도구로 무제한 생성 요금제를 새로 출시했다.
  • Adobe Photoshop — 생성된 이미지를 후보정하고 여러 버전을 조합하는 전문 이미지 편집 소프트웨어
  • ChatGPT Codex — 개발 환경에 ChatGPT 기능을 직접 통합하여 코딩 중에 이미지 생성 등의 작업을 바로 수행할 수 있게 하는 개발자 도구.
  • DALL-E — OpenAI의 AI 이미지 생성 모델

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
