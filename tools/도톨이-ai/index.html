도톨이 AI는 블로그를 운영하면서 글감 찾기부터 초안 작성, 최종 검수까지 한 번에 도움을 받고 싶은 사람에게 맞는 Windows용 프로그램입니다. 내 블로그를 분석하고 키워드를 탐색하는 기능이 포함되어 있어, 어떤 주제로 글을 써야 할지 고민이 많은 블로거에게 도움이 될 수 있습니다. 블로그 작업 흐름을 한 프로그램 안에서 정리하고 싶은 분에게 적합합니다. 다만 가격이나 무료 제공 여부에 대한 정보는 확인되지 않았으므로, 사용 전에 공식 안내를 함께 살펴보시는 것이 좋습니다.

사람들은 이렇게 써요

  • 내 블로그 주제와 말투를 분석해 글감 탐색, 초안 작성, 최종 검수까지 이어 주는 프로그램이다. 자동 발행과 이미지 생성은 v1.0에서 지원하지 않는다
  • v1.2 는 대표 이미지 1장과 본문 이미지 5~10장을 문단 단위 노드 캔버스로 구성한다. 문단마다 담을 내용(제품·대상 디테일, 사용 활용, 방법 과정, 비교 선택 기준 등)과 표현 방식(카드뉴스, 스마트폰 생활 사진, 깔끔한 제품 사진, 광고·홍보, 감성 분위기)을 고르며 프롬프트는 영문으로 내장돼 있다. 공통 참고 이미지는 최대 10장까지 모든 문단에 적용된다
  • 네이버 블로그 글쓰기를 돕는 무료 프로그램. v1.3 은 Windows·Mac 모두 지원하고 Claude 연결·진단 기능이 늘었다. 네이버의 C-Rank(블로그 전체 신뢰도)·D.I.A.(글 한 편의 품질) 기준을 맞추도록 돕는다
  • 설치 시 파란 경고창은 유료 코드 서명이 없어서 뜬다. GPT 카드 로그인 후 테두리에 색이 들어오면 연결 성공이다. 네이버 API Hub·검색광고 API 로 키워드를 분석하고 초안과 이미지를 만든다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • 네이버 블로그 — 한국의 대표 블로그 플랫폼으로 글 작성, 검색 최적화, 수익화가 가능하다.
  • App Store — iOS 앱 배포 플랫폼으로 최종 앱을 사용자에게 공개하는 곳
  • ECC — 오픈소스 Agent Harness로 Claude Code의 작업 환경을 구축하는 운영체계다.
  • Grok — xAI의 AI 어시스턴트로 영상 관련 작업 지원 가능.
  • Hermes — AI 에이전트로, 사용자의 명령을 받아 자동으로 작업 단계를 수행할 수 있는 대규모 언어 모델 기반 기술

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
