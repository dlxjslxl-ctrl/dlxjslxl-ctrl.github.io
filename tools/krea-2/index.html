이런 분께 추천

Krea 2는 텍스트 설명을 입력하면 고품질 이미지를 만들어 주는 AI 이미지 생성 모델입니다. 글로 떠올린 장면이나 분위기를 빠르게 시각물로 옮기고 싶은 사람에게 맞습니다. 예를 들어 콘셉트 이미지나 아이디어 스케치가 필요한 기획자, 디자이너, 콘텐츠 제작자가 참고하기 좋습니다. 다만 가격, 무료 제공 여부, 최신 소식에 대한 정보는 현재 확인할 수 없으니 사용 전에 공식 자료에서 직접 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • Krea 3 는 Krea 2 의 미적 다양성과 개인화 기능 위에 만들었다. Krea 2 는 이미지 모델 가중치를 오픈소스로 공개해 호응을 얻었고, Krea 3 도 공개해 달라는 요청이 있다
  • 텍스트-이미지 생성 기능이 MiniMax H3 원클릭 체인과 같은 ComfyUI 환경에 통합돼 로컬 영상 제작 솔루션에 쓰였다
  • 「KREA2 Identity 로라 팩트체크」 글에도 나온다. 글 요약: KREA2의 새로운 Identity 로라를 실제로 테스트해 결과를 확인했다. (글 기준)
  • 「Krea2와 LTX2.3으로 AI 광고 영상 한 번에 제작하기」 글에도 나온다. 글 요약: Krea2로 이미지 생성 후 LTX2.3으로 영상화해 광고 콘텐츠를 효율적으로 제작하는 워크플로. (글 기준)
  • Krea 2 Turbo 는 오픈 웨이트(공개된 가중치)로 나와 자기 GPU 에서 직접 실행할 수 있다 (글 기준)
  • Raw 는 추가 학습·미세 조정에 맞는 비증류 모델, Turbo 는 2K 이미지를 빠르게 만들고 일반 PC 에서도 돌아간다. 허깅페이스에서 무료로 받고 개인·소규모 기업도 상업적으로 쓸 수 있는 라이선스다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • LTX 2.5 — 텍스트 프롬프트로부터 고품질 동영상을 생성하는 AI 영상 생성 모델
  • Midjourney — AI 이미지 생성 도구로, 텍스트 프롬프트를 입력해 고품질 이미지를 만들 수 있습니다.
  • Qwen-Image-2.1 — 텍스트 입력과 이미지 편집을 통합 처리하는 경량 오픈소스 이미지 생성·편집 모델로, 투명 배경과 다중 참고 이미지를 지원합니다.
  • DALL-E — OpenAI의 AI 이미지 생성 모델
  • GPT — 텍스트 프롬프트로 콘텐츠를 생성하는 AI 모델

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
