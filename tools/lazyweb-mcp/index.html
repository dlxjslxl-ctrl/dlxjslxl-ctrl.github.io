실제 화면과 A/B 실험 결과를 바탕으로 개선안을 제시하는 MCP

무료 여부확인 필요
가격확인 필요
관련 글 수1

사람들은 이렇게 써요

  • 실제 앱 화면·흐름 281,000장 넘는 자료에서 A/B 실험으로 실제로 이긴 것을 찾고, 내 사이트 주소 하나로 점검 리포트와 고칠 일 목록을 준다. 연결과 검색은 무료이고 전체 리포트는 Pro 다. 연결 뒤 이메일로 받은 6자리 코드로 로그인한다
  • 화면 개선안에 실제 A/B 테스트 결과와 사례를 붙여, 감이 아닌 근거로 이유를 설명하게 한다
  • 결제 없이 연결할 수 있고, 실제 화면과 A/B 실험 근거를 바탕으로 고쳐야 할 곳을 짚어 준다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Refero MCP — UI 설계 전 실제 앱 화면을 조사하고 비교할 수 있는 MCP
  • chrome-devtools-mcp — AI 에이전트가 실제 Chrome 브라우저의 개발자 도구 기능을 사용할 수 있게 해 주는 MCP 서버다.
  • InspoAI MCP — 앱 화면·아이콘을 검색하면서 색·폰트 정보도 함께 얻는 MCP
  • Mobbin — 60만 개 이상의 실제 앱과 웹 화면 스크린샷을 모아 놓은 UI/UX 레퍼런스 라이브러리다.
  • Muse — 메타가 공개한 AI 에이전트로 이메일·쇼핑·예약 등 실제 작업을 자동으로 수행하는 개인용 AI 어시스턴트

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
