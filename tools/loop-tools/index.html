Loop Tools는 Blender 안에서 정점 정렬, 평활화, 변형 작업을 자동화해 주는 애드온입니다. 메시를 다루며 반복적으로 정점을 맞추거나 면을 부드럽게 다듬어야 하는 3D 모델러에게 잘 맞습니다. 이런 작업을 손으로 하나씩 처리하는 데 시간이 많이 드는 사람이라면 작업 흐름을 줄이는 데 도움이 될 수 있습니다. 다만 제공된 정보에는 가격, 무료 여부, 최신 소식이 없으므로 사용 전에 공식 자료에서 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • Relax 기능은 Interpolation을 Cubic, Input을 Selection으로 두고 Iterations를 3 이상으로 올려 부드러움을 조절하며, 자동차·캐릭터 같은 곡면 모델링에 특히 유용하다
  • Blender에 내장된 도구로 정점들을 한 줄로 정렬해 주며 초급자도 쉽게 쓸 수 있고, 정렬된 정점은 초록색 체크 표시로 확인한다
  • Space는 선택한 엣지들의 간격을 같은 길이로 균일하게 펴 주고 Relax를 두세 번 적용하면 꼭짓점 위치가 주변과 어울리게 부드러워진다. Space는 UV 메뉴가 아니라 Edge 메뉴에 있다
  • 엣지 루프를 균등하게 배치하고 부드럽게 만드는 Blender의 메시 정리 도구이며 Space로 균등 배치하고 Relax를 한두 번 반복하면 엣지 라인이 더 자연스러워진다
  • 원형 루프를 만들 때 Loop Tools 애드온은 회전이 틀어질 수 있어, 우클릭 메뉴의 기본 Circle 도구가 각도 조정 없이 더 예측 가능하다고 한다
  • Blender 5.3 부터 별도 애드온 설치 없이 기본 기능으로 들어왔다. 'Fit Edge Loops To Annotation'은 그리기(annotation)로 표시한 선에 edge loop 를 맞춰 붙이는 기능으로, Factor 값(예시 0.379)으로 붙는 정도를, Method(Spread 등)로 배치 방식을 정하고 Lock 의 X·Y·Z 로 특정 축 이동을 막는다. Delete Str
  • 무료 애드온 12개 정리에서 메시 루프를 원형·평탄화 등으로 편집하는 모델링 도구로 소개된다
  • 정점을 고르고 오른쪽 클릭 → Loop Tools → Relax 로 점들을 주변과 어울리게 고르게 편다. 왼쪽 아래 조정 패널에서 Type·Strength 를 바꾸고, 과하면 강도를 낮춘다. Edit > Preferences > Add-ons 에서 켜서 쓴다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.
