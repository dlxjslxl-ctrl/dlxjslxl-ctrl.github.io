이런 분께 추천

REA는 AI 에이전트가 앱이나 바이너리를 분석해 기능이 어떻게 구현되었는지 파악하고, 이를 다시 만들 수 있도록 돕는 역공학 도구입니다. 소프트웨어가 내부에서 어떻게 동작하는지 이해하고 싶은 보안 연구자나 개발자에게 맞을 수 있습니다. 다른 제품의 동작 방식을 분석해 참고하려는 사람이라면 관심을 가져볼 만합니다. 다만 가격과 무료 제공 여부에 대한 정보가 없으므로 사용 전에 공식 자료를 확인하는 것이 좋습니다. 또한 역공학은 관련 법규와 라이선스를 지켜서 사용해야 합니다.

사람들은 이렇게 써요

  • Reverse Engineer Anything의 줄임말로 Native 바이너리, JavaScript, Electron 앱, .NET 어셈블리, 웹사이트를 분석한다. 분석은 로컬에서만 실행되고 터미널에서 npx rea-agents setup으로 설정한다
  • Reverse Engineer Anything의 약자로, Ghidra, Hopper, IDA 같은 역공학 도구를 MCP로 AI 에이전트에 연결해 주는 오픈소스다. 분석 대상 바이너리를 외부 서버에 올리지 않고 내 로컬 환경에서 분석한다고 알려져 있다.
  • 에이전트를 분석 도구에 연결하는 MCP 서버로, 소스 코드가 없는 앱의 바이너리, JavaScript, Electron, .NET, 웹사이트 등을 검사할 수 있다. 결과에는 각 결론의 근거와 한계가 함께 담긴다.
  • 모든 코드를 마법처럼 되살리는 것이 아니라 Hopper·Ghidra·IDA 같은 기존 분석 도구를 AI 와 이어 분석을 돕는 방식이다. 설정을 바꾸기 전에 기존 설정 파일 백업이 자동으로 만들어지고, 검증한 버전으로 고정해 쓰기를 권한다(업데이트는 rea update 또는 npx rea-agents@latest setup). APK 와 Flutter 앱도 분석 대상이다
  • 네이티브 바이너리 분석에는 Hopper·Ghidra·IDA 중 하나가 필요하지만 JavaScript·Electron 앱은 별도 분석 엔진 없이 Node.js 만 있으면 된다. '노트 앱에서 검색이 어떻게 작동하는지 근거와 함께 보여 줘'처럼 대상 앱과 기능을 적어 질문하면 분석이 시작된다
  • 직접 만든 노트 앱 NoteVault 의 전용 파일(.nvlt)을 읽는 파이썬 함수를 만들게 한 실험에서, REA 를 붙인 에이전트와 붙이지 않은 에이전트 모두 정상 파일 8개·손상 파일 8개 총 16개를 다 맞혔다. 그래서 REA 의 강점은 '새 기술'이 아니라 분석 도구를 MCP·CLI 로 빠르게 부르고 조사 순서를 스킬로 잡아 주는 '속도와 체계화'라고 평가한다
  • 컴파일된 실행 파일(바이너리), 앱, 실행 중 동작을 한꺼번에 분석한다. 분석은 Analysis pass 단계로 나뉘어 로그에 코드 섹션 디스어셈블, 추가 코드 영역 탐지, 포매팅 같은 단계가 순서대로 표시된다. 라이선스는 MIT 이고 GitHub 트렌딩 1위에 올랐다고 한다
  • Electron 메모 앱 실습에서 렌더러 → preload(window.notes) → IPC(notes:search, notes:copy) → 메인 핸들러로 이어지는 연결을 파일 줄 번호까지 찾아냈다. 분석은 내 컴퓨터에서 하지만 결과는 에이전트를 거쳐 모델 제공자에게 전달될 수 있어, 내가 만든 것이나 분석 권한이 있는 것만 대상으로 삼으라고 한다.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Hopper — macOS와 Linux에서 바이너리를 분석하는 역어셈블리 도구
  • Mobbin — 60만 개 이상의 실제 앱과 웹 화면 스크린샷을 모아 놓은 UI/UX 레퍼런스 라이브러리다.
  • Seedance — AI 영상 생성 플랫폼으로 프레임락 기능을 통해 일관된 움직임과 시각효과를 구현
  • mattpocock-skills — 요구사항 정리·TDD·디버깅·구조 개선 등 실전 엔지니어링을 돕는 스킬 모음
  • n8n — Zapier와 Make의 오픈소스 대안으로 280+ 앱과 서비스를 자동화하는 노드 기반 워크플로 플랫폼
