agent-desktop은 AI 에이전트가 macOS, Windows, Linux 컴퓨터 화면에 있는 프로그램을 직접 조작하도록 도와주는 오픈소스 도구입니다. 반복적인 화면 작업을 AI에게 맡기고 싶은 개발자나 자동화를 실험해 보려는 사람에게 잘 맞습니다. 이 도구는 오픈소스라는 점이 특징이며, 가격이나 무료 여부에 대한 정보는 제공된 자료에 없습니다. 따라서 도입을 고려한다면 공식 저장소나 문서에서 라이선스와 사용 조건을 직접 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 화면 사진 대신 OS 접근성 트리를 읽어 버튼·입력창을 직접 누르는 오픈소스 CLI. snapshot 으로 ref 번호를 받고 click @ref 로 동작시킨다. 기본은 뒤에서 조용히 도는 헤드리스, 실제 입력이 필요하면 --headed. macOS·Windows·Linux, Apache-2.0 (글 기준)
  • 기존 agent-browser 가 웹 브라우저 안만 다뤘다면 이 도구는 메모장·계산기·설정 같은 프로그램까지 컴퓨터 전체를 조작한다. 에이전트마다 독립된 가상 마우스 커서를 써서 동시에 다른 작업을 할 수 있다 (글 기준)
  • Vercel 이 만든 도구. 스크린샷 대신 운영체제의 접근성 트리를 읽어 버튼마다 ref 가 달린 JSON 을 주고, 에이전트가 ref 로 클릭 · 입력한다. macOS · Windows · Linux 지원, npm install -g agent-desktop 로 설치 (하루 만에 3,792 스타, 글 기준)
  • 모델은 들어 있지 않다. 판단은 쓰는 에이전트가 하고 agent-desktop 은 보고 조작하는 손발 역할만 한다
  • 설치 후 agent-desktop status 로 권한을 확인한다. macOS 는 agent-desktop permissions --guide 로 손쉬운 사용 권한을 안내받는다
  • 기본은 헤드리스(마우스 포인터와 포커스를 움직이지 않음), --headed 를 주면 실제 마우스 · 키보드 입력을 쓴다
  • ref 에는 스냅샷 ID 가 들어 있어 @e8 처럼만 쓰면 INVALID_ARGS 오류, 화면이 바뀌면 STALE_REF 오류가 난다. 이때 새 스냅샷을 찍는다
  • CLI 이자 C 라이브러리. 픽셀 비교를 하지 않아 화면 해상도 차이에 덜 흔들린다. 'Playwright 가 웹에서 하던 일을 데스크톱에서 한다'는 비유

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • earshot — 코딩 에이전트가 소리를 듣고, 검토하고, 코드로 소리를 만들 수 있게 해 주는 CPU 전용 오픈소스 도구.
  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구
  • Computer Use — AI가 마우스와 키보드를 직접 조작해 계산, 파일 열기 등 컴퓨터 작업을 수행하는 플러그인.
  • OpenUI — AI 모델이 만든 화면을 스트리밍으로 바로 그려 주는 오픈소스 Generative UI 프레임워크.
  • agent-skills — AI 코딩 에이전트가 따라야 할 엔지니어링 스킬과 프로세스를 정의한 오픈소스 프레임워크

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
