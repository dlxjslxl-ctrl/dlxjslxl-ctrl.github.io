Skill Recorder는 화면에서 하는 반복 작업을 녹화해서, AI 에이전트가 따라 실행할 수 있는 자동화 스킬로 만들어 주는 마이크로소프트의 데스크톱 앱입니다. 매번 같은 순서로 클릭하고 입력하는 업무가 많은 사람에게 잘 맞습니다. 예를 들어 정해진 절차의 문서 작업이나 프로그램 조작을 한 번 보여 주면, 다음부터는 AI가 그 흐름을 대신 수행하도록 설정할 수 있습니다. 다만 가격이나 무료 제공 여부에 대한 정보는 주어진 자료에 없으므로, 사용 전에 공식 안내를 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • v0.7.0 에 Review SKILL.md 버튼이 생겨, 설치·내보내기 전에 frontmatter 까지 전체 내용을 읽기 전용 창에서 볼 수 있다. 고치려면 계획(plan)을 편집해 새 미리보기를 만들어야 하며 검토는 선택 사항이다. Windows 11(x64, ARM64)·macOS·Ubuntu 를 지원하고 MIT 라이선스다
  • 녹화한 작업을 GitHub Copilot CLI 가 사용자의 의도와 단계별 순서를 글로 바꿔 준다. 프롬프트 없이 실제 작업만 보여 주면 된다 (글 기준)
  • 클릭, 페이지 이동, 창 전환을 분석해 SKILL.md 파일로 저장하거나 Microsoft Scout 에이전트가 반복 실행할 자동화로 만든다 (글 기준)
  • 클릭 좌표를 그대로 재생하지 않고 gh CLI 같은 실제 도구를 쓰는 방식으로 바꿔 저장한다. 폼 제출 같은 작업 하나를 녹화하면 비슷한 작업 전체에 쓰는 스킬로 일반화한다 (글 기준)
  • 오픈소스 프로젝트이고 GitHub 별이 3,328개라고 한다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Claude Desktop — 클로드의 데스크톱 애플리케이션으로 화면 녹화 기능을 통해 업무 자동화 스킬을 생성할 수 있다.
  • Browser Use — 웹사이트를 직접 조작하는 AI 에이전트로, Jev와 연결해 자동화 작업을 할 수 있다
  • Chrome DevTools MCP — 크롬 개발자 도구를 기반으로 외부 AI 에이전트와 연결해 자동화 작업을 수행하는 프로토콜.
  • Dots — 오픈AI의 24시간 자동화 에이전트로, 사용자의 목표와 권한에 따라 업무와 생활 작업을 클라우드에서 자동 처리합니다.
  • Agent Skills — 구글의 제품과 기술을 AI 에이전트가 정확하게 배우고 활용하도록 하는 기술 스킬 모음

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
