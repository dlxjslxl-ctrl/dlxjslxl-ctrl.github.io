Agent Skills는 구글의 제품과 기술을 AI 에이전트가 정확하게 이해하고 활용할 수 있도록 돕는 기술 스킬 모음입니다. 구글 제품이나 기술을 바탕으로 AI 에이전트를 만들거나 개선하려는 개발자에게 잘 맞는 도구로 볼 수 있습니다. 제공된 정보에는 가격이나 무료 여부, 최근 소식에 대한 내용이 없으므로 이 부분은 공식 자료에서 직접 확인하는 것이 좋습니다. 구체적인 사용법이나 세부 기능은 주어진 설명만으로는 알 수 없으니, 도입 전에 문서를 살펴보는 것을 권합니다.

사람들은 이렇게 써요

  • 구글이 공식적으로 자기 제품 사용법을 Agent Skills 형태로 만들어 배포해, AI 가 옛날 방식이 아닌 최신 방식을 알게 한다 (글 기준)
  • 프롬프트나 일반 학습으로는 놓치기 쉬운 최신 업데이트와 공식 작업 순서를 AI 가 정확히 따르게 한다고 한다 (글 기준)
  • 깃허브에서 별 1만 8천 개를 받아 개발자들 사이에서 빠르게 쓰이고 있다고 한다 (작성자 수치)
  • 개발자가 자기 AI 에이전트에 추가하면 구글 제품 질문에 더 정확하고 최신의 답을 받는다고 한다 (글 기준)
  • 같은 이름의 다른 것: Meng To(Design+Code 창업자)의 디자인 스킬 75개 GitHub 라이브러리도 'Agent Skills' 로 소개된다. Web Design 62 · Codex 10 · Media 2 · UI 1개, Codex · Claude Code · Cursor 에서 쓴다
  • 그중 video-to-superprompt 는 화면 녹화 영상을 레이아웃 · 모션 · 색 · 구현 방식이 담긴 상세 프롬프트로 바꾸고, html-to-interaction-prompts 는 HTML 을 인터랙션 프롬프트로 바꾼다. 랜딩페이지 전체 캡처를 넣으면 섹션별 프롬프트가 나온다
  • 인물이 든 영상은 사람이 블록 도형으로 단순화되니 Unsplash 같은 실제 사진 URL 을 프롬프트에 넣어 보완한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Diagram Design — 코딩 에이전트가 브랜드에 맞춘 다이어그램을 HTML+SVG 파일로 그려주는 스킬
  • Matt Pocock's Skills — AI 코딩 에이전트의 실제 개발 문제를 해결하는 재사용 가능한 스킬 모음
  • appllama — 매출이 높은 실제 모바일 앱을 레퍼런스로 모아 AI 에이전트가 앱 디자인을 만들도록 돕는 스킬 라이브러리.
  • ffmpeg-skill — Claude Code 등 코딩 에이전트가 로컬 FFmpeg로 영상을 편집하도록 돕는 스킬
  • mattpocock-skills — 요구사항 정리·TDD·디버깅·구조 개선 등 실전 엔지니어링을 돕는 스킬 모음

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
