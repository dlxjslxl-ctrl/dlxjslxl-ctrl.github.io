이런 분께 추천

Geometry Nodes는 Blender에 들어 있는 절차 모델링 및 애니메이션 시스템입니다. 노드를 연결해 형태를 만드는 방식이라, 같은 규칙으로 여러 모델을 자동으로 생성하거나 수정하고 싶은 사람에게 맞습니다. 3D 모델링이나 애니메이션 작업을 하면서 반복적인 작업을 줄이고 싶은 사용자에게 적합한 도구로 볼 수 있습니다. 가격이나 무료 여부, 최신 소식에 대한 정보는 주어진 자료에 없으므로 따로 확인이 필요합니다.

사람들은 이렇게 써요

  • 이미지의 색을 점 밀도와 굵기로 바꿔 평면 위에 천 질감 초상화를 만드는 설정법이 소개됐다
  • Empty 와 각 오브젝트 사이 거리를 Distance 노드로 재고 Map Range → Combine XYZ 의 Z → Translate Instances 에 이으면, Empty 가 움직일 때 도미노가 파도처럼 위아래로 움직인다. Collection Info 는 Transform Space 를 Relative 로, Separate Children 을 켜서 쓴다
  • 깨진 벽돌담: 그리드 평면의 정점·면을 점으로 바꿔 벽돌을 인스턴스로 올리고 짝수·홀수 줄을 어긋나게 하면 쌓기 패턴이 된다. Brick Info 그룹 노드에 너비·깊이·높이·모르타르 값을 모아 두면 한 번만 고쳐도 전체에 반영된다. Geometry Proximity 와 Map Range 로 한 점 주변 범위의 벽돌만 지우고, 시뮬레이션 존에서 매 프레임 점을 추가해 파괴 영역을 칠한다. N
  • Geometry Nodes의 Raycast와 Simulation으로 캐릭터 발자국을 지면에 누적 표현하고 마스크로 셰이더까지 연결하는 방법 (글 기준)
  • 「Blender 지오메트리 노드로 만드는 오프로드 차량 리그 generator」 글에도 나온다. 글 요약: Blenderesse의 무료 오프로드 차량 리그 generator로 경로를 따라 달리는 차량 애니메이션을 절차적으로 만든다.
  • 「Blender 지오메트리 노드로 자동차 하나를 다른 차로 변형하기」 글에도 나온다. 글 요약: 두 자동차 컬렉션을 지오메트리 노드로 나누고 빈 오브젝트 위치에 따라 한 차가 다른 차로 바뀌는 효과를 만든다
  • 「Blender 지오메트리 노드로 만드는 절차적 건물 붕괴 효과」 글에도 나온다. 글 요약: 층 하나를 평면으로 모델링해 지오메트리 노드로 건물 전체와 붕괴 효과를 자동 생성하는 방법

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • Maya — 3D 모델링, 애니메이션, VFX 제작을 위한 전문 소프트웨어
  • Claude Motion — 보고서나 차트를 짧은 애니메이션 설명 영상으로 만드는 기능
  • Cycles — Blender의 물리 기반 렌더 엔진.
  • EEVEE — Blender의 실시간 렌더 엔진

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
