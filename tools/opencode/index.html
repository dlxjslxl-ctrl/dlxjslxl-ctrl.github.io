사람들은 이렇게 써요

  • Free Claude Code 로 무료 모델에 연결할 수 있는 코딩 에이전트 중 하나
  • Agency 에이전트를 설치할 수 있는 도구 목록에 나온다
  • 오픈 소스 AI 코딩 에이전트로 터미널·IDE·데스크톱에서 쓸 수 있고 여러 모델을 연결할 수 있다. 코드나 컨텍스트 데이터를 저장하지 않으며 월간 1,600만 명 이상이 사용하고 GitHub 스타가 208,000개 이상이라고 한다
  • 각 저장소를 설치할 수 있는 코딩 에이전트 환경 중 하나로 소개됐다
  • Core 를 로컬 AI 서버로 쓸 수 있는 외부 도구의 하나로 언급됐다
  • Token Optimizer 가 호환하는 AI 코딩 에이전트로 함께 소개됐다
  • obsidian-skills 를 쓰려면 저장소 전체를 ~/.opencode/skills/obsidian-skills 에 클론해야 한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리
  • GitHub — 오픈소스 코드 저장소
  • 21st.dev — 실험적인 UI 컴포넌트와 그 구현 코드 소스를 제공하는 인터랙션 디자인 레퍼런스 사이트다.
  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구
  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
