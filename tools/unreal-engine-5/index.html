사람들은 이렇게 써요

  • Cinematics(Sequencer, Cine Camera, Camera Rig) + 실시간 렌더로 AI 영상 프리비즈에 최적
  • Fast Character Rigging 결과를 바로 쓸 수 있는 엔진
  • AI 프롬프트로 장면을 만들고 "버섯 제거"처럼 프롬프트를 바꿔 요소를 빼거나, 전부 지우고 동굴 장면으로 다시 구성하는 반복 수정 사례. 달빛·모닥불·안개로 조명 분위기도 프롬프트로 바꾼다
  • 시네마틱 PBR 마스터 매터리얼을 만들어 Base Color·Metalness·Roughness·Normal Map·Reflection 등을 파라미터로 조절한다. Material Graph 로 연결 구조를 한눈에 본다
  • 실무 팁 V2026: 뷰포트 W/E/R 이동·회전·스케일, F 초점, Ctrl+1~9 카메라 북마크. MRQ 는 정적 장면 AA 2/16·TSR, 모션블러가 많으면 AA 16/16~32/32, 웜업 프레임 128/128. 첫 프레임 오류는 마야 애니 앞에 5프레임 추가, 건물이 사라지면 스태틱 메시 Bound 를 100 으로

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • Higgsfield — Claude 기반의 3D 공간 설계와 건축 모델링 플랫폼
  • Higgsfield 3D Jutsu — 텍스트 프롬프트로 3D 장면의 블록아웃을 자동 생성하는 AI 도구.
  • Three.js — 웹 브라우저에서 3D 그래픽을 구현하는 JavaScript 라이브러리

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
