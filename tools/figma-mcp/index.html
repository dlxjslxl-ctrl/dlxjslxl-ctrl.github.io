사람들은 이렇게 써요

  • 코드 → Figma 프레임, Figma 수정 → 코드 반영. MCP 서버 주소 https://mcp.figma.com/mcp
  • Claude Code 가 Figma 파일 구조를 읽고 캔버스에 직접 쓰게 함
  • 디자인 토큰 추출 → 컴포넌트 생성 → QA Reporter 에이전트가 Figma 원본과 비교해 마크다운 리포트
  • 디자인 시스템의 컴포넌트·변수·레이아웃을 Claude 와 연결해 코드와 디자인의 일관성을 유지한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Antigravity — AI를 활용해 디자인 요소와 이미지를 자동으로 생성하고 최적화하는 도구.
  • Google NotebookLM — 구글의 AI 기반 연구·정리 도구로 문서, 영상, 링크를 분석해 요약, 슬라이드, 팟캐스트를 자동 생성합니다.
  • Higgsfield 3D Jutsu — 텍스트 프롬프트로 3D 장면의 블록아웃을 자동 생성하는 AI 도구.
  • NotebookLM — 음성이나 텍스트 자료를 입력해 요약과 인사이트를 자동 생성하는 도구.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
