오픈소스 언어모델을 로컬에서 실행하는 도구

무료 여부확인 필요
가격확인 필요
관련 글 수9

사람들은 이렇게 써요

  • 판단 AI를 로컬에 설치해 운영비 0원으로 돌리는 도구. LM Studio에서도 작동
  • 노트북에서 AI 모델을 직접 실행해 API 비용을 없애 준다
  • 터미널에서 ollama pull gemma3로 모델을 설치한다
  • localhost:11434에서 모델을 띄우면 OpenAI와 Anthropic 호환 방식으로 기존 툴을 그대로 쓸 수 있고, OLLAMA_CONTEXT_LENGTH 환경 변수로 컨텍스트 길이를 정한다
  • EmbeddingGemma 2를 지원하는 도구 중 하나다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구
  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • Connect AI — 로컬에서 실행되는 AI 에이전트로, PayPal 매출 분석 등 비즈니스 작업을 자동으로 관리할 수 있다.
  • DESIGN.md — AI 에이전트를 위해 UI 디자인 규칙·색상·폰트를 구조화된 텍스트 포맷으로 정의하는 구글의 오픈소스 사양
  • Docker — 컨테이너화된 환경에서 애플리케이션을 실행하는 도구다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
