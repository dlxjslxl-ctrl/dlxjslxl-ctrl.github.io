이런 분께 추천

MCP는 Blender에서 3D 작업을 자동화하고 싶은 사람에게 맞는 도구입니다. 반복적인 모델링이나 장면 설정을 줄이고 싶은 3D 작업자나 Blender 사용자가 주로 고려해볼 만합니다. 기본 기능은 무료로 소개되어 있지만, 공식 가격 페이지는 직접 확인하지 못했으니 사용 전 최신 요금을 꼭 확인하는 것이 좋습니다. 커뮤니티 프로젝트 mcp-for-blender는 생성 기능에 대해 월 10~20달러 수준의 유료 Premium이 있다는 2차 보도가 있으니 참고만 하세요. Blender Lab MCP 서버 1.0.3 버전이 2026년 9월 11일에 나왔다는 2차 출처 보도도 있습니다.

사람들은 이렇게 써요

  • Claude Code, Codex, Cursor 같은 MCP 지원 에이전트에서 자연어 질문으로 공공데이터를 검색할 수 있다 (글 기준)
  • 「한컴오피스 2024 실시간 편집 가능한 MCP 공유」 글에도 나온다. 글 요약: 한컴오피스 2024의 HWPX 형식을 실시간으로 편집할 수 있는 오픈소스 MCP 도구. (글 기준)
  • 「Claude Code를 활용한 에이전트 OS 구축의 20가지 핵심 개념」 글에도 나온다. 글 요약: Claude Code로 자동화된 비즈니스를 운영하기 위해 알아야 할 20가지 필수 개념을 시각적으로 정리한 가이드. (글 기준)
  • 「Claude Code로 일주일에 한 번만 작업하고 자동화하기」 글에도 나온다. 글 요약: Claude Code의 Managed Agents와 스킬·프롬프트를 활용해 반복 업무를 자동화하는 9단계 가이드. (글 기준)
  • Astryx 는 AI 에이전트가 CLI·MCP 로 쓰기 좋게 설계됐다고 소개
  • JADX-AI-MCP·apktool-mcp-server 처럼 역컴파일 도구를 AI 에이전트에 연결하는 MCP 서버가 소개됨
  • Claude Code·MCP 클라이언트와 함께 쓰는 에이전트 실행 환경
  • Claude Code·Codex·ChatGPT·Cursor 같은 MCP 클라이언트를 한 번 연결하면 AI 가 캔버스에 직접 스케치·수정

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Loop Tools — Blender 내 정점 정렬, 평활화, 변형 작업을 자동화하는 애드온.
  • AI 렌더링 — 3D 모델에서 최종 시각화 단계를 AI로 처리하는 기술
  • Aside — 로그인된 계정 내에서 이메일, 문서, 웹 작업을 자동으로 처리하는 AI 브라우저 에이전트
  • Blender — 오픈소스 3D 모델링, 렌더링, 애니메이션 소프트웨어
  • Browser Use — 웹사이트를 직접 조작하는 AI 에이전트로, Jev와 연결해 자동화 작업을 할 수 있다

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
