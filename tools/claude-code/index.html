사람들은 이렇게 써요

  • v2.1.224 이상(Windows 는 2.1.234 이상)에서 세션끼리 메시지를 주고받는 기능이 켜진다. 같은 컴퓨터 세션은 서버를 거치지 않고 직접 연결되고, 다른 컴퓨터 세션에는 답장만 할 수 있다고 한다 (글 기준)
  • 세션 간 메시지는 전체 대화 기록이 아니라 필요한 요약만 보낸다. ListAgents 도구로 연결 가능한 세션을 볼 수 있다 (글 기준)
  • 「클로드 코드에 붙여 쓰는 깃허브 도구 10가지」 글에도 나온다. 글 요약: AI 티 나는 글·디자인을 고치고 도식·코드 정리까지 돕는 Claude Code용 깃허브 도구 10개를 소개한다. (글 기준)
  • 「클로드코드에 맡기는 스킬 찾기 find-skills 설치와 확인법」 글에도 나온다. 글 요약: find-skills 로 하려는 일을 말하면 클로드코드용 스킬을 찾아 설치 전 정보와 함께 보여 준다 (글 기준)
  • 「AI로 디자인 덜 엉성하게 만드는 레퍼런스 사이트 5곳」 글에도 나온다. 글 요약: AI 에이전트에게 실제 디자인 레퍼런스를 먹여 결과물 품질을 높이는 사이트 5곳 소개 (글 기준)
  • 「반응형 애니메이션 도감 - AI에게 프롬프트째 넘기는 UI 패턴 모음」 글에도 나온다. 글 요약: 애니메이션·재질·차트 등 UI 패턴을 골라 프롬프트를 복사해 AI에게 주면 구현해 주는 도감 (글 기준)
  • 「AI가 대충 끝내는 걸 막는 unlazy 스킬 (Depth Tree 방식)」 글에도 나온다. 글 요약: 긴 AI 작업을 여러 층으로 쪼개고 각 조각에 전체 시간을 주어 대충 끝내는 것을 막는 Claude·Codex용 스킬 (글 기준)
  • 「Hypit으로 잘나가는 쇼츠 구조를 복제하는 AI 워크플로」 글에도 나온다. 글 요약: 잘나가는 쇼츠를 넣으면 AI가 컷·자막·B롤·효과를 뜯어 같은 구조로 다시 만들어 주는 오픈소스 스킬 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Claude — Anthropic이 만든 AI 어시스턴트로 바이브 코딩 작업을 수행합니다.
  • Copilot — GitHub와 Microsoft가 제공하는 AI 코딩 어시스턴트로 CLI에서 활용 가능하다.
  • Grok — xAI의 AI 어시스턴트로 영상 관련 작업 지원 가능.
  • 21st.dev — 실험적인 UI 컴포넌트와 그 구현 코드 소스를 제공하는 인터랙션 디자인 레퍼런스 사이트다.
  • Anthropic Claude API — Anthropic의 클로드 AI 모델을 API 형태로 제공하며, ComfyUI에 연결해 자동으로 프롬프트를 생성할 수 있다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
