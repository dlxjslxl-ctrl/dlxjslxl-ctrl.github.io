사람들은 이렇게 써요

  • 「Claude Code로 40+ 종류 다이어그램 자동 생성」 글에 함께 나온 도구
  • 텍스트 설명을 HTML과 SVG 다이어그램으로 바꿔 주는 오픈소스 스킬로 42가지 유형을 지원한다. 각 다이어그램은 빌드 단계 JavaScript 외부 이미지 없이 브라우저에서 바로 열린다. GitHub 별은 약 4.35만 개다
  • 45가지 다이어그램 유형(구조도·시퀀스도·상태 머신·간트·사분면 등)을 지원하고 에이전트가 유형을 고르고 계획을 먼저 설명한다. 결과물은 인라인 SVG 가 든 HTML 파일 하나라 더블클릭으로 열리고 SVG·PNG 로 내보낼 수 있다. 디자인 원칙은 그림자 없음·1px 선·4px 격자·강조 색 1~2개다. 한계: 결과 품질이 모델에 따라 다르고 같은 요청도 배치가 매번 달라지며, 텍스트 편집
  • 10선에서는 6만 스타로 소개된 45종 다이어그램 에이전트 스킬 (브랜드 컬러·폰트에 맞춘 HTML+SVG 한 파일) (작성자 수치)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • Claude-Mem — Claude Code 플러그인으로 세션 관찰과 요약을 로컬 데이터베이스에 저장해 다음 세션에 맥락을 불러옵니다.
  • Orca — Claude Code와 Codex 세션을 스마트폰과 연결해 원격으로 감독하는 앱
  • 21st — React 컴포넌트·템플릿·테마 12,000개 이상을 한곳에 모은 라이브러리로, Claude Code로 자동 생성 가능.
  • Browserling — 해외 원격 브라우저 서비스로 다른 국가의 IP 주소를 사용할 수 있게 해준다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
