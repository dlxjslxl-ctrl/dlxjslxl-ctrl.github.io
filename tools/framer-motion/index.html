이런 분께 추천

Framer Motion은 React 애플리케이션에 애니메이션을 더하고 싶은 개발자에게 맞는 React 애니메이션 라이브러리입니다. React 프로젝트에서 화면 요소의 움직임을 구현하려는 사람이라면 검토해 볼 만합니다. 주어진 정보에는 가격이나 무료 제공 여부, 최신 소식이 포함되어 있지 않아 이에 대해서는 확인할 수 없습니다. 사용하기 전에 공식 자료에서 최신 정보를 직접 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 「UI 개발 속도를 높이는 AI 프롬프트 라이브러리 10개」 글에 함께 나온 도구
  • React StatsCard 에서 whileHover={{ y: -5 }} 로 호버 시 카드를 띄우는 데 쓴다 (원본의 도구 칸 이름은 framer-motion)
  • 카드 바깥 div 를 motion.div 로 두고 whileHover={{ y: -5 }} 를 주면 마우스를 올릴 때 카드가 위로 떠오른다
  • motion.div 에 whileHover={{ y: -5 }} 를 주면 마우스를 올릴 때 카드가 위로 5px 떠오른다 (글 기준)
  • 「Glass Sidebar V2 React 접이식 사이드바 구현 과정」: React와 Framer Motion으로 열고 닫히는 유리(glass) 느낌의 사이드바 메뉴를 만드는 과정을 코드와 함께 보여준다.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Magic UI — React 기반의 애니메이션 UI 컴포넌트 라이브러리
  • Remotion — React 기반으로 코드로 영상을 작성하고 편집·렌더링하는 라이브러리
  • framer-motion — React에서 움직임과 애니메이션 효과를 쉽게 넣는 라이브러리
  • shadcn/ui — Radix UI와 Tailwind CSS 기반의 React 컴포넌트 라이브러리
  • 21st — React 컴포넌트·템플릿·테마 12,000개 이상을 한곳에 모은 라이브러리로, Claude Code로 자동 생성 가능.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
