codebase-memory-mcp는 Claude에 연결하는 코드베이스 메모리 서버로, 프로젝트의 구조를 기억해 두고 개발 중에 코드를 빠르게 찾는 데 도움을 주는 도구입니다. 따라서 Claude를 활용해 여러 파일이 얽힌 큰 프로젝트에서 코드를 찾아보거나 구조를 파악하려는 개발자에게 잘 맞습니다. 반대로 코드베이스가 작아 직접 찾아보는 것이 더 빠른 경우에는 굳이 필요하지 않을 수 있습니다. 제공된 정보에는 가격이나 무료 여부, 최신 소식이 없으므로 사용 조건은 공식 자료에서 따로 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • Claude Code 는 새 세션마다 프로젝트를 처음 보듯 파일을 찾느라 시간과 토큰을 낭비한다. 이 도구는 그 문제를 푸는 메모리 서버다
  • 설치 후 'X 기능 어디 있나?' 하고 물으면 정확한 위치를 바로 답한다. 프로젝트가 클수록 시간 절약 효과가 크다고 한다 (글 기준)
  • 기억 파일을 팀 저장소에 저장하면 팀원이 clone 한 뒤 같은 기억으로 시작할 수 있다
  • 모든 처리가 로컬에서 이루어져 코드가 밖으로 나가지 않고, 소스가 공개돼 있다. API 키나 의존성 없이 단일 바이너리로 작동하며 MIT 라이선스이고, 릴리스마다 바이러스토탈로 검증한다고 한다 (글 기준)
  • 주의: 인덱스 파일이 소스 옆에 생기므로 회사 코드라면 공유 범위를 미리 확인해야 한다
  • Claude, Cursor, Codex 등 43개 코딩 도구를 지원한다고 한다 (글 기준)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • CLAUDE.md — Claude Code 프로젝트 내 설정 파일로, 멈춤 규칙, 안내문, 메모리 등 지속적 지시문을 저장한다.
  • Genspark — AI가 코드를 작성해주는 웹개발 플랫폼으로, 대화만으로 웹사이트를 만들 수 있다.
  • Google AntiGravity — 에이전트형 IDE로 브라우저와 개발 환경을 연결해 코드를 자동으로 실행·수정하는 개발 도구
  • Google Colab — 클라우드 기반 주피터 노트북으로 강화학습 코드를 무료로 실행하고 로봇 두뇌를 훈련할 수 있다.
  • Surface Scatter — UE5의 절차적 자산 배치 도구로, 메시 표면에 다양한 3D 자산을 빠르게 배치할 수 있다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
