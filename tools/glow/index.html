glow는 마크다운 형식의 파일을 터미널 안에서 보기 좋게 정리해 보여주는 도구입니다. 그래서 README나 문서 파일을 자주 읽는 개발자나, 터미널을 떠나지 않고 글을 확인하고 싶은 사람에게 잘 맞습니다. 마크다운 문법을 직접 보는 것보다 제목과 목록이 구분된 화면으로 읽고 싶을 때 쓸 만합니다. 다만 가격이나 무료 여부에 대한 정보는 주어진 자료에 없으므로 사용 전에 공식 자료를 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 「펜테스트 자동화 도구 PentestCode 사용법」 글에 함께 나온 도구
  • Glow 이펙트는 여러 번 중복 적용한 뒤 Glow Radius를 조정하면 밝기와 강도를 세밀하게 제어할 수 있다
  • Glow Operation을 Add로, Glow Colors를 Original Colors로 두면 원래 색상을 살리면서 빛 효과를 더한다. Glow Intensity 값을 바꾸면 글로우의 선명함과 부드러움이 달라진다
  • 중간 레이어에 Glow Threshold 40, Glow Radius 70, Glow Intensity 1.5로 설정해 버블 같은 광택감을 연출한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Getdesign.md — 마크다운 파일을 프레젠테이션 슬라이드로 변환하는 오픈소스 도구로 자동 디자인을 적용한다.
  • CapCut — 모바일 및 데스크톱 비디오 편집 도구로 생성된 자막 파일을 임포트해 편집할 수 있다.
  • Obsidian Web Clipper — 웹브라우저에서 웹페이지를 캡처해 Obsidian 볼트에 마크다운 형식으로 저장하는 확장 프로그램

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
