Claude Code 등 코딩 에이전트가 로컬 FFmpeg로 영상을 편집하도록 돕는 스킬

무료 여부확인 필요
가격확인 필요
관련 글 수2

사람들은 이렇게 써요

  • Claude Code·Cursor·Codex 에서 클라우드나 API 키 없이 로컬로 돌아간다. probe(길이·해상도·fps 측정) → 가능하면 무손실 편집 → 결과 확인 순서로 파일 사양을 추측하지 않게 한다. 자르기·이어붙이기·무음 제거·비율 맞추기·자막·가라오케 효과·음량 맞추기 등 42개 도구가 있다. 음성 인식(Parakeet·whisper 등)은 선택이며 오디오는 외부로 올라가지
  • Claude Code·Cursor·Codex 같은 코딩 에이전트에 영상 편집 능력을 붙이는 Agent Skill. `npx ffmpeg-skill` 한 줄로 설치하고, probe(측정) → 무손실 편집 → check → verify 순서로 일해 추측 대신 측정값으로 판단한다. 자르기·이어붙이기·무음 제거·자막·HDR→SDR 등 42개 도구를 쓰고, 모두 로컬에서 돌아 클라우드나 API 키가
  • 모든 도구를 MCP 도구로도 부를 수 있다. 기본은 핵심 12개만 보이고 `FFMPEG_SKILL_MCP_FULL=1` 을 설정하면 42개가 모두 보인다. 음성 인식 자막(`caption.py --transcribe`)은 Parakeet 이나 Whisper 가 깔려 있어야 한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Claude-Mem — Claude Code 플러그인으로 세션 관찰과 요약을 로컬 데이터베이스에 저장해 다음 세션에 맥락을 불러옵니다.
  • Diagram Design — 코딩 에이전트가 브랜드에 맞춘 다이어그램을 HTML+SVG 파일로 그려주는 스킬
  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • CLAUDE.md — Claude Code 프로젝트 내 설정 파일로, 멈춤 규칙, 안내문, 메모리 등 지속적 지시문을 저장한다.
  • Hostinger — VPS 호스팅 서비스로 Claude Code 프로젝트를 배포할 때 쓸 수 있다
