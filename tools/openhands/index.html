이런 분께 추천

OpenHands는 직접 서버에 설치해 운영할 수 있는 AI 에이전트 컨트롤 센터입니다. 여러 코딩 에이전트를 한 곳에서 실행하고, 반복되는 개발 작업을 자동화 워크플로로 묶어 관리하는 데 쓰입니다. 따라서 여러 AI 코딩 도구를 함께 다루고 싶거나, 데이터를 외부 서비스가 아닌 자체 환경에 두고 싶은 개발자나 팀에 어울립니다. 다만 가격이나 무료 제공 범위에 대한 정보는 제공된 자료에 없으므로, 도입 전에 공식 자료를 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 직접 호스팅할 수 있는 에이전트 컨트롤 센터. 로컬·Docker·클라우드에서 여러 에이전트를 동시에 돌리고 Slack·GitHub·Linear 와 연동한다. npm 전역 설치 후 agent-canvas 명령으로 실행하거나 Docker 로 격리해 돌린다
  • Agent Canvas 는 코딩 에이전트를 위한 자체 호스팅 개발 제어 센터로, Claude Code·Codex·Gemini 등 여러 에이전트를 로컬·도커·클라우드에서 돌리고 Slack·GitHub·Notion 과 연동해 자동화한다
  • 코딩 작업을 맡기면 스스로 코드를 짜고 실행하는 자율형 AI 개발 에이전트로 소개 (무료 오픈소스 10가지 글)

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Agent-Reach — 여러 플랫폼(X·Reddit·YouTube 등)에서 정보를 수집하는 AI 에이전트 연결 도구.
  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • FreeLLMAPI — 여러 AI 서비스의 무료 API를 연결해 사용 가능한 모델로 작업을 이어가게 돕는 도구
  • Matt Pocock's Skills — AI 코딩 에이전트의 실제 개발 문제를 해결하는 재사용 가능한 스킬 모음
  • OpenClaw — 오픈소스 AI 코딩 에이전트.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
