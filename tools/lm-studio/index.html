이런 분께 추천

LM Studio는 내 컴퓨터에서 오픈 소스 언어 모델을 직접 내려받아 실행할 수 있는 앱입니다. 클라우드 서비스에 데이터를 보내지 않고 로컬에서 모델을 써 보고 싶은 사람에게 맞습니다. 인터넷 연결 없이도 모델을 실행하려는 개발자나 연구자, 학생에게도 적합할 수 있습니다. 다만 주어진 정보에는 가격이나 최신 소식이 없으므로, 비용이나 업데이트 내용은 공식 자료에서 직접 확인하는 것이 좋습니다.

사람들은 이렇게 써요

  • 내 컴퓨터에 AI 모델을 내려받아 무료로 실행하는 프로그램. 버전이 맞지 않으면 서버 오류가 날 수 있고, 버전을 확인해 업데이트하면 대화가 정상으로 돌아온다
  • Gemma 3·Llama 3 같은 모델을 GUI에서 불러오고 API 서버를 열어 Connect AI와 연결한다
  • InkOS 에서 로컬 모델을 연결할 때 쓸 수 있는 앱으로 소개됨

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • ASD-STE100 — 항공우주 정비 문서용 통제 언어로, 명확하고 간결한 표현을 강제하는 언어 스펙.
  • Anthropic Claude API — Anthropic의 클로드 AI 모델을 API 형태로 제공하며, ComfyUI에 연결해 자동으로 프롬프트를 생성할 수 있다.
  • Claude API — Anthropic이 제공하는 Claude AI 모델을 프로그래밍으로 활용할 수 있는 API 서비스
  • Claude Fable — Anthropic의 초장문 컨텍스트와 강화된 추론을 지원하는 언어 모델
  • Claude Opus 5.5 — Anthropic에서 만든 최신 대규모 언어 모델로 Opus보다 저렴하고 빠르다.

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
