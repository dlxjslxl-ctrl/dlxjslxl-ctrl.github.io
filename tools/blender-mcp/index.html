Blender MCP는 ChatGPT가 Blender를 원격으로 제어할 수 있도록 연결해 주는 애드온입니다. 3D 작업을 자주 하면서 AI 도구와 Blender를 함께 쓰고 싶은 사람에게 맞습니다. 다만 가격이나 무료 여부에 대한 정보는 주어진 자료에 없으므로 사용 전에 직접 확인하는 것이 좋습니다. 최신 소식도 아직 정리되어 있지 않습니다.

사람들은 이렇게 써요

  • 「Claude Opus 5.5와 Blender로 AI 영상 카메라 제어하기」 글에 함께 나온 도구
  • uvx mcp-for-blender install-addon으로 애드온을 설치하고 Blender의 Add-ons에서 켠 뒤 서버를 시작한다. 이 연결을 거쳐야 AI가 Blender 장면을 직접 조작할 수 있다
  • ChatGPT 가 Blender 를 직접 제어하게 이어 주는 애드온이며 zip 설치가 편해서 이것을 골랐고 더 잘 업데이트되는 다른 Blender MCP 도 있다고 작성자는 말한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Loop Tools — Blender 내 정점 정렬, 평활화, 변형 작업을 자동화하는 애드온.
  • Orca — Claude Code와 Codex 세션을 스마트폰과 연결해 원격으로 감독하는 앱

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
