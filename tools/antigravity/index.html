이런 분께 추천

Antigravity는 AI 기술을 이용하여 디자인 요소와 이미지를 자동으로 만들고 개선하는 도구입니다. 디자인 작업에 많은 시간을 들이고 싶지 않은 사람들이나 빠르게 시각 자료를 만들어야 하는 직종의 사람들에게 유용합니다. 기본 디자인 지식이 없어도 쉽게 사용할 수 있으므로 마케팅, 콘텐츠 제작, 웹디자인 등 다양한 분야에서 도움이 될 수 있습니다.

사람들은 이렇게 써요

  • Figma 레이아웃 위에 디자인 요소를 자동 생성하는 AI 도구로 소개
  • 브라우저와 개발 환경을 연결해 코드를 스스로 실행·수정·리팩토링하고 테스트·디버깅까지 진행하는 에이전트형 IDE
  • 광고 이미지 자동 생성의 준비 과정에서 설치하는 도구로 안내 (원본은 Google 의 Genie(구글 안티그래비티)라고 적음)
  • AI 에이전트에게 Stitch CLI 를 직접 쓰라고 지시할 수 있어 사람이 매번 명령어를 입력하지 않아도 된다
  • 코딩을 몰라도 프롬프트 한 줄로 웹사이트 뼈대(Next.js+Tailwind)를 만들고 업로드·스타일 선택 UI를 붙일 수 있는 개발 도구(IDE)로 쓰였다
  • HeadshotPro의 무료 미니 버전을 직접 만드는 데 쓴다. 셀카 업로드, 스타일 선택, AI 이미지 생성, PNG 다운로드 흐름으로 만든다
  • 구글 딥마인드의 과학 스킬 37종을 붙이면 한국어로 말만 해도 에이전트가 알맞은 스킬을 골라 뒤에서 스크립트를 돌리고 결과를 정리해 준다
  • Google의 AI 코딩 에이전트 도구로 복잡한 작업을 자동으로 처리하고 코드를 작성할 수 있다고 한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Adobe Firefly — 텍스트 입력으로 이미지를 생성하고 편집할 수 있는 Adobe의 생성형 AI 도구입니다.
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
  • Adobe Illustrator — 벡터 기반 그래픽 디자인 소프트웨어로 스티커 카드를 정밀하게 제작할 수 있다.
  • Adobe Photoshop — 생성된 이미지를 후보정하고 여러 버전을 조합하는 전문 이미지 편집 소프트웨어
  • Aside — 로그인된 계정 내에서 이메일, 문서, 웹 작업을 자동으로 처리하는 AI 브라우저 에이전트

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
