관련 글 수1

사람들은 이렇게 써요

  • 대시보드·설정·로그인·요금 페이지 같은 화면을 찾고, 온보딩 순서·결제 과정 같은 흐름을 통째로 참고하게 해 준다. 유료 계정에서 열리고 추가 요금은 없다
  • SaaS 웹앱 화면 레퍼런스가 필요할 때 고르는 MCP 로 소개된다
  • 잘 만든 서비스 화면과 사용자 흐름을 보여 주며, MCP 를 쓰려면 유료 계정이 필요하다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • InspoAI MCP — 앱 화면·아이콘을 검색하면서 색·폰트 정보도 함께 얻는 MCP
  • Claude — Anthropic이 만든 AI 어시스턴트로 바이브 코딩 작업을 수행합니다.
  • Claude Desktop — 클로드의 데스크톱 애플리케이션으로 화면 녹화 기능을 통해 업무 자동화 스킬을 생성할 수 있다.
  • Claude Opus 5.5 — Anthropic에서 만든 최신 대규모 언어 모델로 Opus보다 저렴하고 빠르다.
  • GitHub Copilot — 깃허브와 OpenAI가 만든 AI 코딩 보조 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
