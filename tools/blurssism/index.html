관련 글 수3

사람들은 이렇게 써요

  • 1.3.1에서 웹 기본 팔레트 7종 블루 인디고 바이올렛 틸 에메랄드 핑크 그래파이트가 추가됐다. 기존 카페인 팔레트 6종과 기본값 에스프레소는 유지하고 팔레트를 두 묶음으로 나눠 관리한다. 노랑과 빨강은 경고 오류색과 혼동될 수 있어 일부러 뺐다
  • 1.4.0에서 기존 글래스모피즘 표현을 블러레마로 바꿨다. 화면의 90% 이상은 종이와 먹 색으로 두고 강조색은 10% 이내로 쓴다. 크레마는 내비게이션 탭바 시트 토스트처럼 떠 있는 요소에만 쓰고 카드 입력창 리스트는 불투명하게 둔다
  • 블러 위에 우유 거품 색 거품 결 캐러멜빛 띠를 겹친 블러레마 크레마가 핵심이다. 화면의 90% 이상은 종이와 먹 색으로 채우고 강조색은 10% 이내만 쓴다. 기본 팔레트는 13종이고 모든 조합이 7,884개까지 WCAG 대비를 통과한다

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리
  • DESIGN.md — AI 에이전트를 위해 UI 디자인 규칙·색상·폰트를 구조화된 텍스트 포맷으로 정의하는 구글의 오픈소스 사양
  • UI UX Pro Max — AI가 검색 가능한 디자인 지식베이스를 활용해 규칙 기반 UI/UX를 생성하는 GitHub 오픈소스 스킬
  • Adobe Illustrator — 벡터 기반 그래픽 디자인 소프트웨어로 스티커 카드를 정밀하게 제작할 수 있다.
  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
