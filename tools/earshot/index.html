earshot — 요금·무료 여부·쓰는 법

업데이트 2026-10-20

코딩 에이전트가 소리를 듣고, 검토하고, 코드로 소리를 만들 수 있게 해 주는 CPU 전용 오픈소스 도구.

무료 여부확인 필요
가격확인 필요
관련 글 수1

사람들은 이렇게 써요

  • AI 코딩 에이전트는 영상·데모·게임을 만들지만 결과물의 소리는 듣지 못한다. earshot 은 이 빈틈을 메운다.
  • 명령은 describe(소리를 말로 풀이), match(설명과 소리가 얼마나 맞는지 판정), find(긴 녹음에서 맞는 구간을 초 단위로 찾기), timeline(영상 소리를 시간별로 기록하고 화면 컷과 맞는지 확인), critique(런치 영상 기준 채점), forge(물리 합성 레시피로 소리를 만들고 반복 개선) 로 나뉜다.
  • GPU 없이 CPU 만으로 돌고, CLI·Python API·MCP 서버 세 방식으로 쓸 수 있다. Claude Code 에는 MCP 서버로 연결하는 쪽이 모델을 메모리에 계속 둬서 빠르다고 한다.

AI 활용 글 여러 개에서 이 도구가 나온 대목을 모아 정리했어요.

쓰는 법

  1. 공식 사이트에서 가입해요 (무료 체험이 있는지 먼저 확인).
  2. 요금제 화면에서 무료로 쓸 수 있는 양과 유료 가격을 확인해요.
  3. 작은 작업 하나로 먼저 결과를 확인하고, 마음에 들면 유료로 바꿔요.

비슷한 도구

  • chrome-devtools-mcp — AI 에이전트가 실제 Chrome 브라우저의 개발자 도구 기능을 사용할 수 있게 해 주는 MCP 서버다.
  • Agent Reach — AI 에이전트에게 SNS·유튜브·깃허브 등 인터넷 전체를 읽고 검색할 수 있는 능력을 주는 오픈소스 CLI 도구
  • Free Claude Code — Claude Code와 다른 코딩 에이전트를 무료로 실행할 수 있는 오픈소스 로컬 프록시.
  • OpenClaw — 오픈소스 AI 코딩 에이전트.
  • Agency Agents — 개발·디자인·마케팅·영업 등 279개 전문가 역할을 정의한 오픈소스 에이전트 라이브러리

가격·무료 여부는 정보 날짜 기준이에요. 바뀔 수 있으니 공식 사이트에서 꼭 확인하세요.
